## 0. 一句话结论

**结果属于 C 类：摩擦方向确实被偏向对手，但水平位移没有改善。**

- 进动转速被调制，平均偏向与理论值吻合。
- 实际倾斜跟随了目标倾斜。
- 相对碗面法线的倾斜方向改变了。
- 推断摩擦方向明显偏向对手：b = 0.6 时，摩擦在对手方向上的分量从 −0.26 m/s² 变成 +0.16 m/s²。

但水平运动没有改善：
- 10 s 净位移没有变好（b = 0.6 时反而下降）。
- 低速占比仍是 100%。
- 重新接触：b = 0.3 时 0/24 场，b = 0.6 时 3/24 场。

同时，自转损失随 b 增大，b = 0.6 时转速下降斜率是基线的 1.7 倍。僵持变短主要是因为转速更早耗尽，不是因为走了出去。

## 1. 实施方式与符号核对

### 1.1 注入方式（独立诊断构建）

- `vitest.e5a.config.ts` 在测试运行时，往 `BeyPhysics.ts` 插入一行钩子调用，磁盘上的 src 文件不变。
  - 插入位置：第 524 行自然进动转速算完之后，第 527–531 行原 steering 调制块之后，第 532 行 launch 分支之前。
  - 插入内容：`{ const __h = globalThis.__E5A_RATE; if (__h) rate = __h(this, rate, mag, steering); }`
- 构建时校验：锚点必须恰好出现一次，前文必须是"自然进动 + steering 调制"块，否则构建失败。
- 钩子 `tests/diag/e5a.diag.ts` 的逻辑：
  - 只在"确认僵持 且 breakout ≤ 0 且 b > 0"时返回 `rate·(1 − b·cosΔ)`；
  - 其余情况原样返回输入的 `rate`，所以 b = 0 逐位等价。

### 1.2 坐标系与符号 [代码证据 + 实测]

- 水平坐标 (x, z)，方位角 = atan2(z, x)。
  - 目标倾斜向量 = (sin lean·cos p, cos lean, sin lean·sin p)（第 548–550 行），所以目标倾斜方位 = precession。
  - intent.heading 也用同一约定（第 487 行 `dx·cos(heading) + dz·sin(heading)`）。
- 自然牵引方向取自源码真实使用的定义（第 452–453 行）：(−sin p·spinSign, cos p·spinSign)。
  - 钩子每次调用都与第 528 行 `psi = p + spinSign·π/2` 的方向 (cos psi, sin psi) 核对。三组共 2,926,480 次调用，不一致 0 次。
- 输入 rate 与自然转速公式 `spinSign·−(3 + 80/max(20, mag))` 逐位比较，不一致 0 次。确认僵持中 steering > 0 也是 0 次：牵引门全程关闭，输入就是自然转速。
- 物理方向核对 [推导]：
  - 设轴相对碗面法线朝 t̂ = (cos q, sin q) 倾斜，接触点相对转轴偏向 +t̂。
  - 自转 ω = spinSign·|ω|·up 在接触点产生的滑移是 spinSign·|ω|·rc·θ·(sin q, −cos q)。
  - 摩擦与滑移反向，方向为 spinSign·(−sin q, cos q)，与源码自然牵引方向一致。
- 偏置符号：cosΔ = 1（自然牵引朝向对手）时，进动放慢，相位在该方向停留更久，平均牵引偏向对手；b < 1 保证相位永远沿自然方向转动，不会锁死。
  - 实测时间平均 cosΔ：b = 0.3 为 0.1538（理论 (1−√(1−b²))/b = 0.154）；b = 0.6 为 0.3285（理论 0.333）。符号与大小都正确。[实测]

逐环结论：

1. **环 1（进动速率）成立**。调制按设计生效，平均偏向与理论一致。[实测]
2. **环 2（实际倾斜）成立**。实际倾斜方向随目标偏向对手，配对 48/48。b = 0.6 时跟随误差的 P90 增大到 99°，说明相位走得不均匀时，自稳控制更难跟住。[实测]
3. **环 3（相对碗面法线的倾斜方向）成立，但被稀释**。
   - 路径核查报告担心碗面法线会盖过轴倾斜，这里得到证实：法线倾斜 0.037 rad 不受偏置影响，大于轴倾斜 0.02 rad。
   - 方向变化从环 2 的 +0.475 降到 +0.366。[实测]
   - 基线时相对倾斜方向本身就偏向对手（+0.22）。原因是两台陀螺分处碗心两侧（中心距 P50 1.03 m，各自 r ≈ 0.57），碗面法线指向碗心，也就是指向对手。[实测 + 推导]
4. **环 4（摩擦方向）成立且幅度最大**。b = 0.6 时摩擦从"背离对手"变成"朝向对手"，配对 48/48。数值是按 E1 方法推断的量，不是 Rapier 求解器回写的切向冲量（Rapier 0.19.3 不回写，contactTangentImpulse 恒为 0）。[推导]
5. **环 5（水平运动）基本不成立**。
   - 速度方向确实更朝向对手（cos +0.17 / +0.22）。
   - 但速度大小只有毫米每秒量级（朝对手分量 +1.5 mm/s），10 s 内双方距离只缩短约 8–10 cm。[实测]

### 3.1 为什么摩擦偏了却走不动 [推导 + 物理假设]

- 门控中，朝对手方向的水平受力（每单位质量）如下。
  - b = 0：摩擦 −0.26 + 碗面法向 +0.16 ≈ −0.10 m/s²。
  - b = 0.6：摩擦 +0.16 + 碗面法向 +0.09 ≈ +0.25 m/s²。[推导]
- 游戏滚动阻力（第 502–510 行）每步把速度往回扣 min(速度, 0.448 m/s²·dt)，起到类似静摩擦的作用：净驱动小于 0.448 m/s² 时，速度维持不住。[代码证据]
- 偏置后净驱动 0.25 m/s² 仍低于 0.448，所以只能产生毫米每秒级的爬行和偶发的速度尖峰。门控中速度超过 0.3 m/s 的步数：b = 0 为 46，b = 0.3 为 225，b = 0.6 为 550。[实测]
- 摩擦大小本身受 μλ 限制（μ = 0.06）。按这个机制，偏置最多能把摩擦整个转到对手方向，也到不了 0.448 + 碗面阻碍这个量级。[物理假设，未单独验证]

## 6. 能量变化 [实测 + 推导 + 物理假设]

指标取第一段确认僵持的前 10 s（配对）。

| 项 | b = 0 | b = 0.3 | b = 0.6 |
|---|---|---|---|
| 转速线性斜率（rad/s 每秒） | −1.21 | −1.45 | −2.07 |
| 配对差（48 个样本中变快的个数） | — | −0.24（40/48 更快） | −0.87（48/48 更快） |
| 转动动能损失率 I·ω·\|dω/dt\|（游戏单位，W） | 62 | 74 | 106 |
| 推断摩擦对平动做功功率（W） | 0.038 | 0.031 | 0.002 |

结论：
- 偏置不改 spin decay 代码，衰减项不依赖进动转速。[代码证据] 多出来的自转损失全部来自 Rapier 接触，因为转速每步从刚体角速度读回。[推导]
- 多耗的自转能量没有变成平动动能：摩擦对平动的功率反而接近 0。[推导]
- 可能原因 [物理假设]：
  - 偏置后相对倾斜变大（P50 0.036 → 0.047 rad），接触点偏离转轴更多，自转滑移和摩擦力矩随之增大，耗散增加；
  - 倾斜跟随误差变大（P90 99°），自稳回正项与实际姿态的拉扯可能也有贡献。
  - 两者的份额没有分开测，属于未验证。
- 角动量：偏置只改目标倾斜的方位节奏，不改倾角目标大小。实测门控中轴倾角 P50 基本不变（0.020 / 0.018 / 0.021 rad）。

## 7. 结论分类

| 类别 | 判断 |
|---|---|
| A. 进动速率变了但实际倾斜没跟随 | **否**：环 2 配对 48/48 跟随 |
| B. 倾斜变了但相对碗面法线方向没有有效改变 | **否**：环 3 配对 47/48 改变，但被碗面法线稀释约 1/4 |
| C. 摩擦方向变了但水平位移没有改善 | **是**：环 4 配对 48/48；净位移、低速占比、重新接触均无改善 |
| D. 水平位移改善且重新接触率提高 | **否**：b = 0.6 只有 3/24 场在偏置期间重新接触，且净位移下降、转速耗得更快 |

对架构决策的含义：
- "方向偏置经进动影响摩擦方向"这条作用链已实测成立。
- 但在针尖僵持中，它产生的朝向对手的净驱动约 0.25 m/s²，低于游戏滚动阻力 0.448 m/s²，所以不能把僵持转成运动，代价是更快的自转损失。
- 继续加大 b 会趋近锁相（路径 B 的风险），并进一步加快转速耗尽。
- 本实验不支持把路径 A 作为针尖僵持的修复方向。
