## 5. 观察（描述，不是已证实的根因）

- **截断比例**（PD 生效步中 λ < 1 的比例，S1）：Pa 烈刃 92.5%、森衡 85.2%、磐盾 9.8%、紫曜 7.0%；Pb 21.5% / 12.0% / 0.2% / 0.3%；Pc 2.7% / 1.8% / 0 / 0。回合结果（胜负方、终结类型、原因）与 P0 不同的回合：Pa 68 / 320、Pb 13 / 320、Pc 0 / 320（Pc 有 165 回合逐步轨迹不同，但结果全部相同）。
- **H1 / H3 的方向**：Pa 中烈刃的失衡起始比例中位升到 0.23（P0 0.086），紫曜 0.11——方向与 §4.3 的静力预言一致；但同时 E1a、E1c、E1d 下降、E1b 刚进入 1–4 s，爆裂占比与回合时长跌出产品区间。
- **E1b 与 E4 在三臂中都未达标**：中 / 高转速恢复时间比 0.82–1.13；Pb / Pc 的失衡过程中位（0.67 s）与 P0 几乎相同。按 C1 数据，阻尼项在跟随旋转目标时与刚度项部分抵消（P0 高转速 |α_S| / |α_PD| 中位 0.89–0.93），只截刚度项、阻尼不变时，姿态更“软而不弹”（§3.3 第 3 点），这可能是 E1c / E1d 在 Pa 下降的原因之一——**待验证**，不作结论。
- 森衡的 P8（46.6–53.2%）在 P0 就已低于 70%（52.2%），三臂都未改善。
- M7（合成相位与实际倾斜方位差 > 45° 的步占比）P0 已为 53–75%，Pa 中攻击 / 平衡上升到 61–63%。

## 6. 风险与未解决问题

1. **C2-P 未通过**：低速失衡过程（E1a ≥ 80%、E1b 1–4 s）与撞后恢复随转速变慢（E4 ≥ 1.3）在任何臂都没有出现；只限制刚度项不足以产生预注册定义的“晃了再倒”。
2. **Q3 / Q4 未通过覆盖率验收**（过覆盖）：即使将来某臂其他条件满足，按冻结规则 P4 也只能是不确定；是否接受“只设下限”或调整验收方法，需审核方另行决定（不能事后修改本次口径）。
3. 磐盾 P8 与 G_D 样本不足的问题按预期出现（P0 磐盾可测量 1 场）。
4. P2.1、P2.3.1 两个现有失败测试仍在。
5. 解释口径选择（已在 `m4c-c2p-analysis.diag.ts` 文件头列出）：§8.3 的不确定区间只用于 S1；P4 的 30 下限对两臂四组都检查；区间方法的可用性取覆盖率验收结果；NaN 记不确定。这些选择**不影响本次结论**（三臂的“不满足”都远离不确定区，或不涉及这些规则）。
6. S3 的力度（0.8）、峰值窗口（扰动后 0.5 s）、恢复判据（≤ 扰动前 0.1 s 均值 + 0.03）是实现时的定义，预注册未逐字规定；S3 不参与判定。
