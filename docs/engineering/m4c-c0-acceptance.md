## 1. 改了什么

| 文件 | 内容 |
|---|---|
| `src/game/beys/motionExecutor.ts`（新） | 四个阶段函数 `stepRail` / `stepTraction` / `stepRolling` / `stepPosture`：从原 `preStep` 逐字移入，算式与取值顺序不变；`ExecutorHost`（陀螺状态接口）、`ExecFrame`（一个子步内各阶段共用的局部量，复用不分配）；`EXECUTOR_SWITCH`（回滚开关）、`EXECUTOR_TUNING`（独立参数对象，C0 为空）；`readTipLoad`（只读接地法向力） |

| `tests/diag/m4c0.diag.ts`（新） | 同机耗时对比 |

**分段调用的顺序（与原 preStep 相同）**：读取上一子步 N（只读）→ 姿态 / 速度 / 转速读取、CCD、陀螺项恢复 → 账本对账、基础衰减、刮地、爆裂衰减 →
**轨道冲刺**（读线速度、施加冲量）→ 战术意图更新（读位置、线速度）→ 发射初相恢复 → **牵引**（读线速度——已含本步冲刺冲量；施加冲量）→
**滚动阻力**（读线速度——已含牵引冲量；施加冲量）→ 衰减扣除与账本分摊 → **姿态**（读扣除后的转速；改写横向角速度与进动相位）→ 写回角速度。
每个阶段在原位置自己读取刚体的新鲜状态并立即施加；没有“一次快照、最后统一施加”。

**接地法向力 N 的定义**：子步 k 的 `preStep` 开头读取 ContactService 在子步 k − 1 的 `world.step` 之后观测到的“本台 `bit` ↔ `arena:floor`”
碰撞体对的匹配法向冲量 J（只计本步求解器接触点，旧冲量不计），N = J / dt（dt = `PhysicsWorld.stepDt`）。滞后一拍；
第一步、单台（没有 `contactOwner`）、没有接触观测时 `valid = false`。C0 中 N 不参与任何计算。

## 4. iPhone 帧耗时基线：测量方法（需要 Huang 在真机上执行）

C0 与旧版本逐位等价，所以真机上现有版本的数字就是 C0 之前的基线（C0 本身的真机数字要等授权构建测试 IPA 后再测）。
1. 打开已安装的版本，开始默认对局（森衡 vs 磐盾），画质保持自动。
2. 战斗开始后点右上角帧率角标，展开性能面板。
3. 回合进行中等待约 10 秒，截图面板（含“CPU/帧：物理 X ms（Y 步）”“帧间隔 中位 / P95 / P99”“刷新基准”）。
4. 同一局再隔约 10 秒截一张；共 3 局。
需要的数：物理 ms / 帧、步 / 帧（二者相除 = 每步耗时）、帧间隔 P50 / P95、刷新基准、画质档位、机型与 iOS 版本。
