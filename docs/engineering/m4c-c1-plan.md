## 0. 测量手段与零行为变化保证

- **只读探针** `EXECUTOR_PROBE`（`src/game/beys/motionExecutor.ts`）：默认 `null`；诊断脚本设置后，轨道冲刺 / 牵引 / 滚动阻力 / 姿态四个阶段在原位置把
  已经算出的中间量（施加的冲量、方向、速度上限、咬合度、PD 前后的横向角速度等）交给它。探针不调用任何 Rapier 方法、不写任何状态。
- 证明（单元测试，CI 运行）：① 探针开启与关闭的两个世界并排推进，两台陀螺刚体上的全部读写调用逐位相同；② 探针报告的冲量与刚体实际收到的
  `applyImpulse` 参数逐位相同；③ 探针开启时 golden 逐场一致（REPRO_FULL = 1 时全部 180 场）。
- 接地法向力 N：执行层在子步 k 开头读到的是**上一子步（k − 1）**求解后的轴心-地面法向冲量 / dt（C0 第 7 项）。C1 的所有“μ·N”都用这个滞后量
  （即 C3 实际能用的量），并单独报告它与同一步求解后的 N 的差别（滞后的影响）。
- I_a 一律用游戏层 `spec.spinInertia`（全部自转规则以它为准），不用 `massProps.Ia`；两者的比值单独列出。
  横向力矩与横向角加速度的换算用刚体横向惯量 I_t = `massProps.It`（绕质心，解析值，已由 `clawPhysics.test` 核对）。

## 2. 五组测量

### 2.1 μ_trac、c_g、Ω_ref 的标定量级
- 现有牵引的等效系数 μ_impl = F / N_lag，F = 牵引冲量 / dt（只取实际施加牵引的步）；同时给出 μ_static = F / (m·g·n_y)（用静态法向力，去掉 N 噪声）。
  分构筑 / 轴心、分转速档给 P10 / P25 / P50 / P75 / P90。施加牵引时 N_lag = 0 的比例（空中 / 跳动时施力）单列。
- 现有自稳 PD 的等效力矩 τ_PD = I_t·|Δω_PD| / dt，Δω_PD 为姿态阶段对横向角速度的改变量；K = τ_PD / (I_a·ω)（rad/s，即 c_g·Ω_ref 的乘积）。
- Ω_ref 的候选：① 真实陀螺的重力进动角速度 Ω_p = m·g·l / (I_a·ω)，l = 质心高于接地球心的距离（comY − ρ）；② 现有合成进动角速度
  precessBase + precessSpin / max(20, ω)；③ 实测横向角速度 |ω_⊥| 的中位数。对每个候选给出 c_g = K / Ω_ref 的分布。
- 参照：重力倾倒力矩 τ_g = m·g·l·sin θ 在典型 / 撞击后倾角下的值，与 τ_PD 并列。

### 2.2 d_eff 候选定义与 ω·d_eff 分布
- 候选：d_geo = ρ·sin θ_rel（ρ = 接地球半径 = contactRadius，θ_rel = 转轴与当地地面法线夹角）；d_meas = 轴心-地面最深接触点到转轴直线的距离
  （ContactService 求解前几何，用来核对 d_geo）；d_drift = ρ·sin(drift)（零件设计倾角）；d_rim = ρ（上限：按整圈边缘接地）。
- 分构筑 / 轴心、典型与撞击后两个窗口、三个转速档，给出 θ_rel、ω、ω·d（每种 d）与实际水平速度 |v|、沿牵引方向速度的分位数，以及现有速度上限
  driveSpeed·grip·(0.35 + 0.65·ratio) 的分位数。

### 2.3 现有牵引折算成能量形式的成本
- 牵引做功（每步精确值）W = J·v⁻ + |J|² / (2m)，v⁻ 为牵引阶段读到的线速度（施加前），J 为施加的冲量。
- 功率形式（C3 候选规格）：Δω_P = max(W, 0) / (η·I_a·ω)，报告 η = 1（η < 1 时按 1/η 放大）。
- 力矩形式（接地点摩擦）：Δω_τ = |J|·d / I_a（d 取 2.2 的各候选），隐含 η = W / (|J|·ω·d)。
- 现行固定费率：账本 `drive`（driveSpinCost × grip × 惯量比）。比较 Σ Δω_P、Σ Δω_τ 与 Σ drive 的倍数（检查是否在 10–30 倍量级）。
- 同口径列出：轨道冲刺（W_rail 与账本 `rail`）；姿态做功 P_posture = τ_PD·ω_⊥ = I_t·(Δω_PD·ω_⊥⁻) / dt，以及精确的横向动能增量
  I_t·(ω_⊥⁻·Δω_PD + ½|Δω_PD|²)，若按功率形式从自转扣时的 Δω（现行模型里 PD 不扣转速）；滚动阻力耗散的平动能（只作结构参考）。
- **对回合时长的影响（一阶估计，轨迹不变）**：沿实测轨迹逐步重算假想转速 ω′：ω′ ← ω′ − (该步实际掉速 − 该步账本 drive) − max(W, 0) / (η·I_a·ω′)，
  直到 ω′ < stopSpin。报告：假想停转时刻 / 实际时刻、ω′(结束) / ω(结束)、保持现有时长所需的 η_keep = Σ Δω_P(η = 1) / Σ drive。
  轨迹在新规律下一定会变（牵引变弱、速度变慢），所以这只是量级估计，不作为 C3 的预测。
- 能量结构：每构筑的自转能量预算 ½·I_a·ω₀² 与各账本分项（基础、空气、刮地、牵引、转向、轨道、碰撞、咬合、重击）折算成能量后的占比；回合时长分布。

### 2.4 各执行层约束的作用步占比
在现有模型实际施加牵引 / 姿态力矩的步上，统计如果换成执行层约束，每条约束会“起作用”（截断或清零）的比例：
- N_lag = 0（离地清零）；F > μ·N_lag，μ ∈ {0.1, 0.2, 0.3, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0}；沿牵引方向速度 ≥ ω·d（d 取各候选）；
  τ_PD > K_ref·I_a·ω（K_ref 取 Ω_p、合成进动角速度、1、3、10 rad/s，即 c_g = 1）。
- 现有约束的作用比例：速度上限截断、墙边借用方向不符、转速低于 2·minStableSpin、未接地；PD 饱和段（s 取满）与尾段比例。

### 2.5 接触状态持续时间分布
来自 ContactService 的生命周期事件（`end` 事件给出持续步数）：
- 两台身体级接触段：按对阵分组的持续时间分布（P50 / P90 / P99 / 最大）、≥ 0.5 s / ≥ 1 s / ≥ 2 s 的段数与占回合时间比例，**重点是球头 vs 球头**（紫曜镜像）
  以及含球头 / 针尖的对阵。
- 轴心-地面：离地段（求解器接触消失）的持续时间分布；`grounded` 判定为真但 N_lag = 0 的比例（120 Hz 跳动）。
- 非轴心部件（轴杆、棘轮、刀刃）与地面的接触段；陀螺与墙的接触段。
