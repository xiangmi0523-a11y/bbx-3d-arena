## 3. C2-P 的公式与参数定义

### 3.1 现有 PD（`stepPosture`，逐项对应代码）

记 û 为转轴，p = (p_x, p_y, p_z) 为横向角速度（世界系，已扣除自转分量），ω 为转速，ω₀ 为发射转速，dt = 1/120 s。

- 强度：s = clamp((ω − 7) / (0.3·ω₀), 0, 1)·gyroFactor。
- 目标：倾角 lean = drift·min(1, ω / (0.5·ω₀))，方位 = 合成进动相位 φ_syn；目标方向 t̂ = (sin lean·cos φ_syn, cos lean, sin lean·sin φ_syn)。
- 恢复轴 a = û × t̂，**代码只使用水平分量**：a_x = û_y·t̂_z − û_z·t̂_y，a_z = û_x·t̂_y − û_y·t̂_x（|a| ≈ 角度误差的正弦）。
- **刚度项**（恢复）：α_S = k_s·s·(a_x, 0, a_z)，k_s = uprightStiffness = 320 s⁻²。
- **阻尼项**：α_D = −c_d·s·(p_x, p_y, p_z)，c_d = uprightDamping = 32 s⁻¹。
- **合成**：α_PD = α_S + α_D；p ← p + α_PD·dt。代码直接改横向角速度，所以 α 本身就是横向角加速度（rad/s²）。
- 等效力矩：τ_S = I_t·α_S，τ_D = I_t·α_D，τ_PD = I_t·α_PD（I_t = `massProps.It`）。C1 测的 K = |τ_PD| / (I_a^game·ω) 是**合成后**的量。

### 3.2 C2-P 的预算（只改刚度项）

- 预算：B = c_g·I_a^game·ω·Ω_ref，**Ω_ref ≡ 1 rad/s（常数）**，所以 K_ref ≡ c_g·Ω_ref 数值上等于 c_g。
- 刚度项截断：|α_S| > 0 时 λ = min(1, B / (I_t·|α_S|))；**|α_S| = 0 时令 λ = 1、α_S′ = 0，不计算 B / (I_t·|α_S|)**；α_S′ = λ·α_S。
  B ≥ 0（ω ≥ 0），所以 B = 0 而 |α_S| > 0 时 λ = 0，不会出现除以零；实现中两种情况都有单元测试，保证不产生 NaN / Inf。
  等价地，刚度项的横向角加速度上限为 **α_S,max = K_ref·I_a^game·ω / I_t**。
- 阻尼项不变：α_D′ = α_D。
- 合成：α′ = α_S′ + α_D′；p ← p + α′·dt。
- 其余全部不变：s、lean、合成进动相位（含意图调制、撞歪后相位跟随）、牵引方向 = φ_syn + 90°、陀螺项关、合成刮地、能量账本（**姿态正功不从自转扣，只测量**）。
- 新参数（K_ref 与开关）放在 `EXECUTOR_TUNING` / 独立开关对象，不进 `BEY_TUNING` 与参数指纹；开关关闭时与现有行为逐位相同。

### 3.3 为什么只限制刚度项

1. **阻尼项恒为耗散**：α_D·p = −c_d·s·|p|² ≤ 0，它只减少横向动能，不注入能量；路线报告 §3 的要求是“阻尼项只耗散不注入”。预算要限制的是“把轴拉回来”的能力（陀螺刚度），对应刚度项。
2. **限制阻尼会引入第二种行为变化**：阻尼被截断后系统欠阻尼、产生振荡，结果无法再归因于“恢复能力不足”。
3. **代价**：被截断后，阻尼仍按原强度作用，若刚度被大幅截断，阻尼会相对更强（姿态更“软而不弹”）。P0 臂同时测量 |α_S|、|α_D| 与 |α_PD| 的分布（只读探针扩展），用于解释，不用于改动实验臂。
4. **数据缺口**：C1 只测了合成后的 |α_PD|（K）。PD 在跟随旋转目标时 α_S 与 α_D 会部分抵消，所以 |α_S| 可能明显大于 |α_PD|，§4 的截断估计会偏低。这一点在 P0 臂上实测后写入报告，但不据此改动候选值。

### 3.4 对构筑的含义：刚度上限与重力

C2-P 不开陀螺项：Rapier 里没有陀螺稳定性，竖立完全靠刚度项。对质心取矩，使陀螺倾倒的是接地法向力 N 的力矩 τ_N ≈ N·l·sin θ；
近似 N ≈ m·g（C1：S1 对战中四构筑 N_lag 的均值为 1.05–1.09 m·g，口径见下）、平地、忽略接地摩擦力对质心的力矩时，τ_N ≈ m·g·l·sin θ，对应横向角加速度 m·g·l·sin θ / I_t。
刚度项受预算时能撑住倾角 θ 的**必要条件**是 α_S,max ≥ m·g·l·sin θ / I_t，即
ω ≥ ω_hold(θ) = m·g·l·sin θ / (I_a^game·K_ref)（I_t 在两边约去）。是否真能撑住还取决于现有的强度 s 与误差大小（α_S = 320·s·sin 误差）。这是静力估计，只用于解释 H3，不是门槛。

**参数来源**：
- g = 20：`src/game/physics/PhysicsWorld.ts` 中 `GRAVITY = -20`、`PHYSICS_EXPERIMENT.gravity = -GRAVITY`，世界重力向量为 (0, −g, 0)（构造函数 `new R.World({ x: 0, y: -this.g, z: 0 })`）；默认值，C2 不改。
- m：刚体质量 `body.mass()`，等于零件总质量（C1 `MC1-META` 的 bodyMass = totalMass）。
- l：`massProps.comY`（质心相对刚体原点 = 接地球底部的高度）− ρ，ρ = `bit.contactRadius`（接地球半径，球心在本地 y = ρ）。
- I_t = `massProps.It`（绕质心），I_a^game = `spec.spinInertia`；数值见 §2.2，取自 C1 `MC1-META`。
- N_lag / (m·g) 的均值（追溯 C1 原始输出 `MC1-AGG` 的 `g1.nLagOverMg`，CI 43129443527）：统计对象是“接地”判定为真（位置判定）、N_lag 有效、发射过渡后、未爆裂的步，每 2 步取 1 个样本，**含 N_lag = 0 的步**，每个“样本 | 构筑”求均值。
  - S1 对战：烈刃 1.052、森衡 1.054、紫曜 1.072、磐盾 1.090 → **1.05–1.09**（与 Muse 独立核查一致）。
  - S2 单台：四签名 1.088 / 1.098 / 1.095 / 1.117（烈刃 / 森衡 / 紫曜 / 磐盾），森衡刀刃换四种轴心 1.067–1.105 → 1.07–1.12。
  - r5 写的 1.05–1.12 是 S1 与 S2 合并后的范围；C2-P 的判定样本是对战样本，所以本文采用 S1 口径。两者差别来自单台没有碰撞、全程接地比例与姿态不同，未进一步分解。

### 3.5 倾倒力臂的推导（r4：对审查意见“l 应为 comY”的核对）

**审查意见**：原点在轴尖最底部，球心 y = ρ，接触点 y = 0，comY 为质心相对原点的高度，所以竖直、平地、法向力作用在球最低点时 l = comY，不应减去 ρ。

**代码事实**（逐项核对，与审查意见一致）：`BeyPhysics.ts` 的接地碰撞体为 `ColliderDesc.ball(bit.contactRadius).setTranslation(0, bit.contactRadius, 0)`，即半径 ρ 的球、球心在本地 y = ρ，球底在本地 y = 0；
`massProps.ts` 中接地球的质量放在 y = ρ（`parts.push({ m: mb, y: rb, … })`），`comY = Σ m·y / Σ m` 是相对刚体原点（球底）的高度。

**推导**（平地，地面法线 ŷ，转轴 û 与 ŷ 夹角 θ）：
1. 球对平面的接触点是球面上离平面最近的点：**接触点 = 球心 − ρ·ŷ**。它始终在球心正下方，倾斜时**不跟随刚体原点**（刚体原点 = 球心 − ρ·û，只有 θ = 0 时才与接触点重合）。
2. 质心 = 球心 + (comY − ρ)·û。
3. 法向力 N·ŷ 作用在接触点，对质心的力矩 τ_N = (接触点 − 质心) × N·ŷ = [−ρ·ŷ − (comY − ρ)·û] × N·ŷ = −(comY − ρ)·N·(û × ŷ)，大小 **N·(comY − ρ)·sin θ**（ŷ × ŷ = 0，ρ 那一项不产生力矩）。
4. 所以倾倒力臂 l = comY − ρ（质心到球心的距离）。只有 θ = 0 时接触点才在 y = 0，而此时 sin θ = 0、力矩为零；对任何 θ ≠ 0 都是 comY − ρ。

**反例核对**：均质实心球（comY = ρ）放在平地上不会倾倒。按 l = comY − ρ 得 0（正确）；按 l = comY 会得到 N·ρ·sin θ 的倾倒力矩（与事实不符）。

**comY 出现在哪里**：接地**摩擦力**（水平，作用在接触点）对质心的力臂是竖直距离 ρ + (comY − ρ)·cos θ ≈ comY（θ 小时）。所以 comY 是摩擦力矩的力臂，不是法向力矩的力臂；§3.4 的近似忽略了摩擦力矩（已列为待核实）。
若接地体是尖点（ρ → 0），两种写法相同；本作四种轴心的 ρ 为 0.045–0.15，差别 11%（磐盾）到 36%（烈刃）。

**结论（r6：已核验）**：l = comY − ρ 已由审查方独立确认，不再列为待审核。本版**保留 l = comY − ρ**，没有按 r4 时的审查意见改为 comY；§2.2、§3.4、§4.2、§4.3 的数值因此与 r3 相同。下表保留“若取 l = comY”时的对照值，只作记录（**不用于任何判定**）。

### 7.1 统计方法与工具支持情况

**抽样单位：场景行。** 数据表的一行 = 一个场景 = (层 h, 场景序号 i)，对应一个种子、一个回合（`matrixScenarios` 每个种子只生成一个回合，不是整场比赛）。同一行内的全部观测（两台、逐步数据）随行整体保留，不拆开抽样。
- **层**：16 个有序对阵（§7.1.1 的表格顺序），层的个数、每层场景数都不变：S1 每层 n_h = 20 行（i = 0–19），S4 每层 n_h = 40 行（i = 0–39）。
- **行上的标签**：每行对每个臂各有一个标签，由该臂在这个回合的实际结果决定，在 bootstrap 中**随行保留、不重新分配**：
  - P4 / M2 / M3：标签 ∈ {G_A, G_D, 无观测}；G_A / G_D 行带一个数值（输方的失衡起始转速比例等），无观测行（非自转终结、超时判定、平局等）不带数值。同一行在 P0 与候选臂上的标签可以不同。
  - P7c：只用涉及该构筑的 6 个层（§8.2 P7c），每行带两臂各一个 0 / 1 的胜负值。
- **一次重抽样（第 b 次，b = 1 … B）**：按层的顺序，对第 h 层抽 n_h 次下标 j = ⌊u·n_h⌋（有放回），得到一个**行的多重集**；被抽中多次的行按次数重复计入。G_A、G_D 等“组”**不单独抽样**，而是由抽中各行的标签决定，所以每次重抽样里各组的观测数会变化。
- **配对**：第 b 次重抽样只生成**一套行下标**，P0 与候选臂共用这同一套下标；各臂按自己在这些行上的标签与数值计算统计量，再相减（例如 (Δ_arm − Δ_P0)_b）。不允许两臂各自抽样。
- **空组**：第 b 次重抽样中，若某个统计量所需的任一组在任一所需的臂上观测数为 0（例如 Δ − Δ_P0 需要 P0 与候选臂各自的 G_A、G_D 都非空），该统计量在第 b 次**无定义**，记为一次退化：
  按 §7.2 不重抽、不补抽、不替换为其他行或其他组，不改变 B；该次从百分位计算中剔除，并记录（b、统计量、为空的组、为空的臂）。只需要 G_A 的统计量不因 G_D 为空而退化。
  P7c 的统计量每次都有 6 层 × n_h 行，不会出现空组。
- 合成测试（§7.1.1–§7.1.6）与正式分析使用完全相同的抽样步骤；区别只在于数据来源与随机数种子（§7.1.5）。

**次数与种子**：B = 2000，随机数种子 12345（`seeded`），百分位法 95% CI（2.5% / 97.5% 分位）。

#### 7.1.2 合成数据的分布、参数与真值

C1 **没有记录每个输方的失衡起始转速比例**（M2 / E6 是 C2-P 才新增的逐台测量；M4-A 只报告了各构筑的中位 0.06–0.11），所以真实分布的形状与离散程度**未知**（待核实：需要 P0 臂运行后的逐台 M2 数据）。
因此不拿任何一种分布去“拟合”游戏，而是用一个**事先固定的分布组**检验方法在对称与偏斜两种形状下的表现；分布组在批准后锁定，**不得在看到覆盖率结果后增删或改参数**。

| 用例 | G_A 分布 | G_D 分布 | 已知真值 | 选择理由 |
|---|---|---|---|---|
| U | 均匀 U(0.04, 0.20) | U(0.02, 0.14) | 中位 0.12 / 0.08，Δ = 0.04 | 对称、有界；中位有闭式解 (a + b) / 2 |
| LN | 对数正态 LN(ln 0.12, 0.5) | LN(ln 0.08, 0.5) | 中位 0.12 / 0.08，Δ = 0.04 | 右偏、取值为正；中位有闭式解 e^μ |
| LN0 | LN(ln 0.10, 0.5) | LN(ln 0.10, 0.5) | Δ = 0 | 零差异时的覆盖 |

- 位置参数：中位取 0.08–0.12，落在 M4-A 单台各构筑失衡起点中位（0.06–0.11）附近；Δ = 0.04 接近 P4 门槛 0.03。这只是让测试落在相关量级，**不是对真实分布的估计**。
- 离散参数（均匀分布的宽度、对数正态的 σ = 0.5）**没有经验依据**，是测试设计的选择（待核实：P0 运行后，用逐台 M2 的实际离散程度判断这组参数是否覆盖得到，结论只用于说明，不回头修改本组测试）。
- 对数正态不截断；本节用到的对数正态（中位 ≤ 0.15、σ = 0.5）取值大于 1 的概率不超过约 10⁻⁴，且不影响中位数。
- **真值**用闭式中位数，不用模拟估计；Δ 的真值 = 两组中位数之差。

#### 7.1.3 覆盖率的计算

对每个用例，生成 N_sim 个独立数据集（建议值 1000）；每个数据集按 §7.1 的抽样步骤（B = 2000，§7.1.5 的种子）求 95% 百分位区间 [L, U]。
- **覆盖**：L ≤ 真值 ≤ U（闭区间，用未舍入的双精度值比较）。
- **退化数据集**：B 次重抽样中出现至少一次退化（§7.1 空组规则）的数据集；按 §7.2 第 4 条，其区间标为“重抽样不稳定”。退化按每个量分别判断（只需要 G_A 的量不因 G_D 为空而退化）。
- 每个用例、每个量**分别报告三个指标，名称固定、不互相替代**：
  1. **有效区间覆盖率** C_valid = 非退化数据集中覆盖真值的个数 / 非退化数据集个数（这是标准意义上的覆盖率，只针对有效区间）；
  2. **退化比例**：退化数据集比例 D_ds = 退化数据集个数 / N_sim，以及退化重抽样比例 D_rs = 全部退化重抽样次数 / (N_sim × B)；
  3. **保守综合指标** C_cons = 非退化数据集中覆盖真值的个数 / N_sim（退化数据集一律按“未覆盖”计）。C_cons **不是**标准统计覆盖率，报告中不得称为“覆盖率”。
- §7.1.6 的接受区间沿用 r6 的规则，适用于 C_cons（即原来“退化数据集按未覆盖计入”的那个量）；C_valid 与 D_ds、D_rs 一并报告，供审核方判断。
  非退化数据集为 0 时 C_valid 无定义，报告“无有效区间”。
- 统计量编号与用例的对应（与 §7.1.5 用例表的“报告的量”一列一致；每个用例只报告表中列出的量，不报告其他量）：

| 编号 | 统计量 | 适用用例 | 组的观测数 |
|---|---|---|---|
| Q1 | G_A 单组中位数 | 单臂 c = 0–5 | S1 布局（c = 0–2）206；S4 推算布局（c = 3–5）412 |
| Q2 | **G_D 单组中位数** | 单臂 c = 0–5 | S1 布局 **22**；S4 推算布局 44 |
| Q3 | Δ = median(G_A) − median(G_D) | 单臂 c = 0–5 | 同 Q1、Q2 |

#### 7.1.4 配对 bootstrap 的两臂数据

**连续量（P4 的 Δ − Δ_P0）**：S1 布局下，每个带观测的场景同时生成两臂的值：
- Z₀、Z′ 为独立标准正态，Z₁ = ρ·Z₀ + √(1 − ρ²)·Z′；X_P0 = exp(μ_P0 + 0.5·Z₀)，X_arm = exp(μ_arm + 0.5·Z₁)。
- ρ ∈ {0, 0.5, 0.8}（建议值）是**对数尺度上的相关系数**（ln X_P0 与 ln X_arm 的皮尔逊相关恰为 ρ；X 本身的相关略小）。
- 中位：P0 的 G_A / G_D 为 0.12 / 0.08（Δ_P0 = 0.04）；候选臂为 0.15 / 0.08（Δ_arm = 0.07），**真值 Δ − Δ_P0 = 0.03**；另设零差用例（候选臂与 P0 同分布，真值 0）。
- 两臂使用**相同的观测位置**（同一组场景带观测）。真实实验中两臂的自转终结场景会不同（§8.2 P4 解释边界），这种“观测位置不一致”的情形**本测试不覆盖**（待核实：需要 P0 与候选臂的实际运行结果才知道不一致的程度），报告中写明。

**二元量（P7c 的胜率变化）**：每个构筑 6 个非镜像对阵 × 20 = 120 个配对场景（S1）。
- 两臂的胜负按给定的边际胜率 p₀、p₁ 与 phi 相关系数 r 生成：P₁₁ = p₀p₁ + r·√(p₀(1 − p₀)p₁(1 − p₁))，P₁₀ = p₀ − P₁₁，P₀₁ = p₁ − P₁₁，P₀₀ = 1 − p₀ − p₁ + P₁₁；每个场景取一个均匀数 u，按 P₁₁、P₁₀、P₀₁、P₀₀ 的累积顺序决定 (W_P0, W_arm)。

  可行性已核对：r = 0.8 时四个格的概率最小为 0.020（p₁ = 0.30）与 0.0455（p₁ = 0.35），都为正。
- 只报告的附加用例：p₀ = 0.95、p₁ = 0.90（接近磐盾 97.5% 的高胜率区）；此时 r 的上限约 0.69，只测 r = 0 与 0.5。

#### 7.1.6 接受标准（建议值，待批准）与依据评估

- **建议**：§7.1.5 用例表中标“验收”的每个用例、每个量的保守综合指标 C_cons（§7.1.3）落在 [0.93, 0.97]，N_sim = 1000；C_valid 与退化比例同时报告。
- **依据只覆盖了蒙特卡罗误差**：N_sim = 1000、真实覆盖率 0.95 时，覆盖率估计的标准误为 √(0.95 × 0.05 / 1000) ≈ 0.0069，[0.93, 0.97] 约为 ±2.9 倍标准误。
- **依据不足之处**（所以不能视为已证实的标准）：
  1. 百分位 bootstrap 对中位数的区间在有限样本下本身就会偏离 95%（小样本尤甚），这一偏差对 n = 22、本分层布局有多大，**没有现成数据**；接受区间把蒙特卡罗误差与方法自身的偏差混在了一起。
  2. 没有产品或统计上的既有要求规定 ±2 个百分点的容差。
  3. 覆盖不足（区间过窄、判定过于乐观）比覆盖过度更危险；是否改为只设下限（例如 ≥ 0.93），需要审核方决定。
- 在这三点由审核方确认前，[0.93, 0.97] 与 N_sim = 1000 只是**建议值**；批准后锁定，**不得在看到覆盖率后修改**。
- 计算量（每个用例 1000 × 2000 次重抽样）在实现时测量；若单元测试时间过长，改在诊断任务中运行，但用例、种子与标准不变。

#### 7.1.7 McNemar 检验规范

定义：对同一组配对场景，b = P0 为 1、候选臂为 0 的场景数，c = P0 为 0、候选臂为 1 的场景数（例如 P7c 中“胜 = 1”）。

- **未校正**：χ² = (b − c)² / (b + c)。
- **连续性校正**：χ²_cc = max(0, |b − c| − 1)² / (b + c)。
- **p 值**：自由度为 1 的卡方分布上尾概率 p = P(χ²₁ ≥ χ²) = erfc(√(χ² / 2))。两种统计量各自计算 p。
- **b + c = 0**（没有不一致的配对）：不计算统计量（避免 0 / 0），报告“b = c = 0，无不一致配对，McNemar 不适用”；**不记为统计分析失败**，也不据此作任何判定；P7c 的判定本来以配对 bootstrap 为准（§8.2）。
- **实现要求**：erfc 必须有文献可查的实现，并通过下表的数值测试。

固定测试输入与预期结果（预期值由 CPython 3 的 `math.erfc` 计算，双精度；其中 χ² = 1 与 3.841458820694124 / 6.634896601021214 对应的 p = 0.31731… / 0.05 / 0.01 是公认的卡方分位点，用于核对 erfc 实现）：

| 10 | 4 | 2.5714285714285716 | 0.10880943004054569 | 1.7857142857142858 | 0.18144920772142034 |
| 15 | 5 | 5.0 | 0.025347318677468252 | 4.05 | 0.04417134490844261 |

数值误差要求：
- χ² 与 χ²_cc 是有理数的双精度计算，与表中值的绝对差 ≤ 1 × 10⁻¹²。
- p 值与表中值的绝对差 ≤ 1 × 10⁻¹⁰（**建议值**：取决于 erfc 实现的精度；常见的双精度实现可达约 10⁻¹⁵，低精度近似公式（约 10⁻⁷）不满足要求，不得使用）。
- b = c = 0 必须返回“不适用”，不得返回 NaN、Infinity 或 0 / 1 等占位值。

### 7.2 bootstrap 的退化重抽样与有效样本不足

1. **先查原始样本**：bootstrap 之前先核对原始观测数是否达到该指标的预注册下限（P4 每组 ≥ 30；P8 S1 ≥ 20、S4 ≥ 40）。不满足时该指标直接记为**不确定**（不是通过，也不是失败）；区间仍可计算，但只作描述并标注“样本不足”。
2. **退化重抽样的定义**：某次重抽样中，计算统计量所需的任一组观测数为 0（例如 G_D 在这次抽样中一个都没有、或配对比较中某臂该组为空），统计量无定义。
3. **处理**：退化的重抽样**不重抽、不补抽、不替换为其他组的样本**，也不缩小或增加 B；它从百分位计算中剔除并计数。
4. **报告与重抽样不稳定**：每个区间同时报告 B、有效重抽样数与退化数；退化数**按统计组**（例如 G_A、G_D、单个构筑）和**配对臂**（P0、候选臂）分别列出，说明是哪一组、哪一臂为空。
   只要出现任何一次退化重抽样，该区间标为“**重抽样不稳定**”，对应指标记为**不确定**。
   这与第 1 条的“**原始样本不足**”是两种不同的状态：原始样本不足由原始观测数判断，重抽样不稳定由重抽样过程判断；原始样本达到下限时仍可能出现重抽样不稳定，报告中分别标注，不互相推断。
5. **统计分析失败**（统计程序报错、抛出异常、得到 NaN / Inf 等非数值结果）：与测量误差分开处理（§8.5）。
   - 不报告该区间，该条件**不作通过或失败判断**，状态记为“统计分析失败（待重算）”；在重算完成前，该臂不能得出最终结果。
   - 修复统计程序（附单元测试）后，用**同一份原始数据**、同一 B、同一随机数种子重新计算；**不重跑物理模拟**，不更换数据。
   - 报告中记录失败原因、修复提交与重算结果。
6. **中位数定义**：偶数个观测取中间两值的均值（与 `m4.metrics.ts` 的 `median` 相同）；百分位区间取第 2.5% / 97.5% 分位，用 `m5b.shared.ts` 的 `quantile`（最近秩）。

### 7.3 计算精度与舍入规则

- 所有派生量由**未舍入的输入**计算：惯量、质量、几何取 C1 `MC1-META` 的完整精度值；实验结果取诊断原始输出。表中显示的输入值只用于阅读，不用于再计算。
- 只在显示时舍入，规则为四舍五入（0.5 进位，远离零）：
  - 质量、惯量、长度、倾角（rad）：3 位小数；惯量比、gyroFactor、转速比例：2 位小数；
  - 横向角加速度上限 α_S,max：整数；倾倒角加速度：1 位小数；ω_hold、转速（rad/s）：1 位小数；
  - 时间（s）：中位与区间 2 位小数，汇总表 1 位小数；
  - 比例 / 胜率 / 占比：百分数 1 位小数；区间端点与点估计同精度。
- **门槛比较一律使用未舍入的值**；舍入后的显示值与门槛恰好相等时，以未舍入值判定，并在报告中写出未舍入值。
- 同一数值在不同表中出现时必须一致（r5 已按此核对 §3.5、§4.2、§4.3）。

- 样本与不确定性：C1 的 P0 筛选集中（§6.4，非超时自转终结的输方）G_A = 206（烈刃 114、森衡 92）、**G_D = 22（磐盾 1、紫曜 21，紫曜约 95%）**。G_D 低于下限 30，**按 P0 的构成，S1 上的 P4 预计为“不确定”**；S4 推算 G_D 约 44，但仍几乎全部来自紫曜。
  候选臂会改变自转终结的数量，实际样本以运行结果为准；任一组观测 < 30 → 该集上 P4 记为“不确定”。CI 按 §7.1 的分层成组 bootstrap；Δ − Δ_P0 用配对 bootstrap。
- 门槛（与 r2 相同）：Δ ≥ 0.03 **且** Δ − Δ_P0 的配对 bootstrap 95% CI 下限 > 0（差异必须比基线大，而不是基线就有的差异）。
- 产品依据：总方案要求每类陀螺“输法不同”（构筑身份）；0.03 的转速比例约 4 rad/s，约 1–2 s 的自然掉速时间，是一段可见的时间差。
- 判定顺序（每个集合独立进行，S4 不并入 S1）：
  1. **先查样本**：任一组观测 < 30，或 §7.2 出现退化重抽样 → **不确定**，不再看点估计；不确定**不写成通过，也不写成失败**。
  2. 样本足够时：Δ ≥ 0.03 且 Δ − Δ_P0 的配对 CI 下限 > 0 → 满足；Δ ≥ 0.03 但 CI 下限 ≤ 0 → 不确定；Δ < 0.03 → 不满足。
  3. S1 上不确定 → 可进入 S4；S4 上不确定 → 报告 Huang（§8.3 有条件结果），不能视为通过。
- **不得替代**：不得用 G_A、S2 单台、S3 探针或其他集合的样本替代磐盾或 G_D 的证据；不得把 G_D 的结论推广到磐盾（G_D 几乎全部来自紫曜，报告中必须写明 G_D 的构成）。
- P4 保留为**机制证据**（见下面的解释边界）。
- **解释边界（r4）**：
  - P4 是**条件性指标**：只描述“发生自转终结时，输方的失衡起点”。样本是“以自转终结输掉的一方”，这一集合本身随实验臂改变（终结方式、谁输、何时输都会变）。
  - **不得把 P4 单独解释为姿态预算造成的因果效果**：两臂的 Δ 之差可能来自样本构成的变化（例如某构筑在候选臂里改为以爆裂 / 出界输掉，或输方的发射力度分布改变），而不是同一陀螺失衡点的改变。
  - **必须同时报告**（每臂、每个集合 S1 / S4）：
    1. 各构筑作为自转终结输方的样本数；
    2. 各构筑作为输方的终结类型分布（自转 / 爆裂 / 出界 / 极限）及平局、未判数；
    3. 两臂样本构成的变化：按配对种子统计每个构筑“两臂都是自转终结输方 / 只在 P0 是 / 只在候选臂是”的种子数，以及输方的发射力度与对阵分布；
    4. 只用“两臂都是自转终结输方”的种子重算的 Δ 与 Δ − Δ_P0（同一批种子，作为构成不变时的对照）。
  - **构成变化的判断是定性审查事项**：没有已确认的数值依据来规定多大的变化算“明显”，本文不设数值门槛；由审查方根据上面 1–4 项判断。
    若审查认为两臂的自转终结样本构成明显变化，P4 的结果只能作为**条件性机制证据**，**不得单独作为产品通过依据**（产品层面的判断依靠 P1、P6、P7、P8 等不以“自转终结输方”为条件的指标与 S2 / S3 单台结果）。

**P7 核心玩法与产品可接受区间**（不再以“保留基线一半”为唯一条件）
- 定义与门槛：
  - P7a 爆裂终结占比：点估计在产品目标 **15–25%**（总方案 §5.4 标准场）内；P0 为 20.3%（65 / 320，Wilson 95% CI 16.3–25.1%）。
  - P7b 回合时长中位：在产品目标 **12–18 s**（§5.4）内；P0 为 13.5 s。
  - P7c 四构筑胜率不被“天然淘汰”（**筛选保护线，不代表构筑平衡已经达标**）：
    - 定义：对每个构筑，在它参与的全部非镜像场景上记胜 = 1、其余（输、平局、未判）= 0；胜率 = 均值（另报告只计已分胜负场景的胜率，作描述）。
      P0 与候选臂在**同一组种子**上得到配对的 0 / 1 序列，变化 Δwin = 胜率_臂 − 胜率_P0。
    - **场景集合**：构筑 X 的 6 个非镜像有序对阵 = X 作为玩家方对另外 3 个构筑（3 层：X-Y）+ X 作为对手方对另外 3 个构筑（3 层：Y-X）；**两种站位都包含**。
      每层 S1 有 20 个场景（i = 0–19）、S4 有 40 个，所以 X 的场景集合在 S1 为 6 × 20 = **120** 行、S4 为 6 × 40 = **240** 行；镜像层 X-X 不包含。
      例如森衡：森衡-烈刃、森衡-磐盾、森衡-紫曜、烈刃-森衡、磐盾-森衡、紫曜-森衡。
    - **胜负的统一定义**：X 在该行的站位 = 玩家方（层为 X-Y）或对手方（层为 Y-X）；W = 1 当且仅当比赛记录的胜方（`winner`）就是 X 的站位，否则 W = 0（输、平局、未判都为 0）。
      超时判定按比赛记录的胜负计入（它是比赛规则产生的结果）；非镜像对阵中的超时判定数另行报告（C1 S1 中为 0，§6.4 的 18 场全在磐盾镜像）。
    - **不重复、不遗漏**：每个非镜像回合同时属于双方两个构筑的集合，在每个构筑的集合里恰好出现一次；12 个非镜像层 × 20 = 240 个回合，4 个构筑的集合合计 4 × 120 = 480 行 = 240 × 2，逐一对应。
      配对按 (层, 场景序号) 对齐：P0 与候选臂的同一行是同一个种子。每个构筑的 Δwin 单独计算、单独判定，不把四个构筑的行合并成一个样本。
    - **bootstrap**：按 X 的 6 个层分层，每层 n_h 行，P0 与候选臂共用同一套行下标（§7.1）。
    - 统计：首选 §7.1 的分层配对 bootstrap 95% CI；McNemar 检验与配对差的 Newcombe 混合 score CI 作对照（两者不一致时以 bootstrap 为准，并在报告中写明）。四个构筑分别报告胜率、Δwin 及其 CI。
    - 门槛（数值与 r2 相同）：每个构筑胜率点估计 ≥ 10%；Δwin 在 S1 上点估计 ≥ −15 个百分点（筛选保护线）、在 S4 上配对 95% CI 下限 ≥ −15 个百分点（确认保护线）。
  - P7d 终结结构：自转 / 爆裂 / 出界 + 极限 / 平局四类分布对 P0 做卡方检验，**只报告**（标准场的自转、出界、极限占比在 P0 就不在 §5.4 目标内，属于 M4-D / M5 的任务）。
- 依据：§5.4 是已确认的产品目标；“一张地图不得让某一类型天然淘汰”（§5 原则 3）；功效表（§13.5）：15 个百分点的差每组约 170 场。
- 样本与不确定性：每个构筑参与的非镜像场景 S1 为 120（6 个对阵 × 20）、S4 为 240。总方案的功效表（15 个百分点每组约 170 场）是按独立两组计算的；
  配对设计的方差取决于两臂结果的相关性，C1 没有这一数据，所以配对下的实际功效**未知**（待核实）——S1 只用点估计作保护线，区间判定放在 S4。P7a 在 n = 320 时 Wilson 半宽约 ±4.5 个点。
- 未达到：P7a / P7b 点估计在区间外但距边界不超过 2 个百分点 / 1 s → **不确定**，进入确认集一次；否则失败。P7c 在 S1 点估计越过保护线 → 失败；在 S4 上 CI 下限越过保护线 → 失败；配对方法尚未实现并通过测试 → P7c 不作判定（不确定），不用独立样本方法替代。
- 说明：P0 的胜率结构（磐盾 97.5%、烈刃 19.7%，按“只计已分胜负”口径）本身不平衡；C2 不负责平衡，P7c 只防止某一构筑被进一步打成“天然淘汰”，通过 P7c **不代表平衡达标**（平衡在 M4-D / M5 按功效样本另行验收）。

**P8 单构筑失衡过程**
- 定义：单构筑的 E1a（该构筑作为自转终结输方的场景中，有失衡过程的比例）。
- 依据：录像 4 / 4 有失衡过程；M4-A 单台的分构筑占比 33–100%（磐盾 33%）；整体门槛 80%（P1）。单构筑样本小，取 70%（比整体低 10 个百分点）防止整体达标而某一构筑完全没有失衡过程。
- **筛选（S1）**：该构筑在 S1 的观测（非超时自转终结的输方，§6.4）≥ 20 时，要求点估计 ≥ 70%；观测 < 20 → 该构筑在 S1 上“不确定”（C1 的 P0：烈刃 114、森衡 92、磐盾 1、紫曜 21）。
- **独立确认（S4）**：只用 S4 的观测重新计算；该构筑在 S4 的观测 ≥ 40 时，要求点估计 ≥ 70% 且 Wilson 95% 下限 ≥ 55%；观测 < 40 → 该构筑“不确定”，**不得借用 S1 样本补足**。
- S1 + S4 合并只作描述性统计（报告合并比例与 Wilson CI），不替代 S4 的确认判定。
- 产品依据：每种构筑输的时候玩家都应看到“晃了再倒”，而不是只有攻击型如此。
- 未达到时：S1 上样本足够而不满足 → 该臂失败；S4 上样本足够而不满足 → 该臂失败；S4 上样本不足 → 该构筑不确定（§8.3）。S2 / S3 的单台结果单独报告，不作通过依据。
- **磐盾（接受预期的不确定）**：磐盾的自转终结几乎全部是镜像超时判定（S1 中 19 场里 18 场），可测量的只有 1 场；按 P0 的比例推算 S4 约 2 场，**预计达不到 S4 的 40 场下限**，磐盾 P8 预计为“不确定”。
  - 超时判定不并入终结、不计入分母（§6.4）；不改变样本定义来凑足样本。
  - 不宣称磐盾 P8 通过或失败；报告中写明“磐盾 P8：不确定（可测量样本 n = …）”。
  - 若之后需要验证磐盾的失衡过程，**另行设计**（例如专门的单台或非镜像实验，单独预注册），不在本次预注册中临时改变样本定义。
- 紫曜：S1 为 21（刚过 20），S4 推算约 42（接近 40），可能落入不确定，按同一规则处理。
- 70%、55% 与 r2 相同；S1 的观测下限 20 为 r3 新增，S4 的下限 40 沿用 r2 的数值但改为只计 S4。均为本文新定的判断值，需要批准。

### 8.3 判定

每个条件在每个集合上的状态只有四种：**满足**、**不满足**、**不确定**（含原始样本不足、重抽样不稳定、§8.2 定义的不确定区间）、**统计分析失败**（§7.2 第 5 条，待重算）。

**第一步：S1 筛选（每臂）**
- 任一条件**不满足**（P1–P3、P6、P7a、P7b 超出下面的不确定区间；P4 样本足够且 Δ < 0.03（§8.2 P4 判定顺序第 2 条）；P7c 越过 S1 保护线；P8 某构筑样本足够而低于 70%；P9 不满足）→ **筛选失败**，该臂不进入 S4。
- 其余情况（全部满足，或只有不确定）→ **进入 S4 候选**。不确定不按失败处理。
- 不确定区间：E1a、E1c、E1d、E5 差距在 3 个百分点以内，E1b 在 0.2 s 以内，E4 在 0.1 以内，P7a / P7b 在 2 个百分点 / 1 s 以内，以及 §8.2 中 P4、P8 的不确定定义。
- 任一条件处于“统计分析失败” → 先按 §8.5 重算，重算前不作筛选结论。
- 多臂进入候选时按 §8.4 选一臂，与 P0 一起送 S4。

**第二步：S4 独立确认（选中的一臂）**
- 只用 S4 的数据重新计算全部条件，**不合并 S1**；P4、P8 的样本下限按 S4 自身的观测数判断，不借用 S1。
- P4 的状态是 **G_A / G_D 两组比较**的状态：例如 G_D 观测 < 30 时写作“P4（G_A / G_D）不确定：G_D 样本不足（n = …，紫曜占 …）”，不写成某个构筑的状态。
- P8 的状态按构筑分别给出：例如“磐盾 P8 不确定：可测量样本 n = …（< 40）”。

**第三步：最终结果**
- **通过**：S4 上全部条件满足（包括四个构筑的 P8 与 P4）。
- **有条件结果**：S4 上没有任何条件不满足，但有条件为不确定（例如 P4（G_A / G_D）不确定、磐盾 P8 不确定）。有条件结果**不是完整通过**，不自动采用，报告列出每个不确定的条件与原因，交 Huang 决定。按 P0 的样本构成（§6.4），P4 与磐盾 P8 预计不确定，所以本实验最可能的最好结果是有条件结果。
- **失败**：S4 上任一条件不满足。
- 任一条件仍处于“统计分析失败”时，不给出最终结果。
- **P4 的使用限制**（§8.2 解释边界）：即使 P4 满足，若审查认定自转终结样本构成明显变化（定性审查），报告中把 P4 标为“条件性机制证据”，最终结果不得只以 P4 为支撑。
- 不确定不会通过修改门槛、合并集合或借用其他样本解决。

### 8.4 选臂规则（多臂进入 S4 候选时）

依次比较：① P8 中满足的构筑数多者；② E1b 中位与 2.0 s 之差小者（录像 1–3 s 的中点）；③ K_ref 大者（截断最少、离现有手感最近）。只把选中的一臂与 P0 送确认集。

### 8.5 失败归类

| 类别 | 判据 | 处理 |
|---|---|---|
| 物理机制失败 | 审计、确定性、测量自检全部通过，指标未达到 | 按 §10 停止条件 |
| 测量误差 | 探针报告的 α 与刚体实际调用不一致；同一数据两种口径不一致；S3 标定不在规定范围 | 修正测量，同种子重跑物理模拟，门槛与样本不变，记录 |
| 统计分析失败 | 统计程序报错、异常或得到 NaN / Inf 等非数值结果（§7.2 第 5 条） | 不报告区间，不作通过或失败判断；修复统计程序并补单元测试后，用同一原始数据、同一 B 与随机数种子重新计算，不重跑物理模拟；记录原因与修复提交 |
| 测试环境问题 | CI 中断 / API 故障；墙钟计时检查在同一提交重跑结果不同（确定性哈希相同） | 同一提交重跑；哈希不同按代码问题处理 |

## 9. C2-G：真实进动——后续研究框架（**不是已完成的预注册**）

> 本节只固定研究顺序（G1 → G2 → G3）与研究问题。本轮不新增 G2 所需的开关、不实施 C2-G；在下面 §9.6 列出的内容补齐并单独审核之前，C2-G 不得运行。

### 9.1 目的

单独测量真实陀螺动力学对进动、移动、牵引方向与战术行为的影响。**C2-G 的结果不归因于姿态预算**；C2-G 不改变刚度预算（PD 与 P0 相同）。

### 9.2 实验臂（逐步只改一项）

| 臂 | 陀螺项 | PD 目标方位 | 牵引方向 | 说明 |
|---|---|---|---|---|
| G0 | 关 | 合成进动相位 | 合成相位 + 90° | = P0 |
| G1 | **开**（`GYRO_EXPERIMENT.enabled = 1`，I_a^phys / I_t） | 合成进动相位 | 合成相位 + 90° | 只加陀螺项：现有 PD 如何与真实动力学叠加 |
| G2 | 开 | **跟随实际转轴方位**（PD 只纠正倾角大小，不再拖动方位） | 合成相位 + 90°（意图调制保留） | 身体的进动由重力与陀螺项决定，牵引方向机制不变 |
| G3 | 开 | 跟随实际方位 | **实际倾斜方位 + 90°**（现有开关 `tiltDrive = 1`；意图调制随之失效） | 只改牵引方向来源，观察对移动与战术的影响 |

G2 将来需要一个新开关（PD 目标方位的来源），本轮不新增；届时按 C0 的方式证明关闭时逐位相同。G1 → G2 → G3 每步只改一项；每臂与前一臂成对比较。

### 9.3 指标

进动角速度（自由运动、θ_v > 0.05 rad 时转轴方位角在 0.25 s 窗口的变化率，按转速档）与 Ω_p = m·g·l / (I_a^phys·ω) 之比；进动方向与重力力矩的夹角余弦；章动幅度；
移动（E2 速度曲线、半径分布、r > 4.0 的时间占比）；牵引方向的变化角速度、与实际方位的夹角；战术（跟进、外圈切入、逼墙、连击链）；E1、E5、P6、P7。

### 9.4 P5 进动物理性（草案，C2-G 预注册时重新审核）

- 定义：S2 高转速档（ω/ω₀ ≥ 0.6）自由运动中，测得的进动角速度 / Ω_p 的中位（每构筑），以及方向余弦的中位。
- 依据：T2（`gyro.test.ts`）在理想球铰上 8 ω_c 时偏差 < 10%；场地内有接地摩擦、碗面坡度与碰撞，偏差会更大；场地内的进动**从未**按此口径测过（B1 未记录）。
- 门槛：比值中位 ∈ [0.7, 1.4]，方向余弦中位 ≥ 0.7，每构筑高转速档样本 ≥ 200。
- 未达到：先用同一测量代码在 T2 场景自检（偏差 > 10% → 测量误差）；自检通过而场地内不满足 → 记为“进动主要由接地摩擦 / 接触决定”（机制结论），G2 / G3 不建议采用，不调整门槛。
- 产品依据：进动是否“由物理产生”是本路线的前提；这一门槛检验机制，不代表手感好坏。

## 10. 回滚与停止条件

**回滚**：C2-P / C2-G 的改动全部在独立开关之后，默认关闭；关闭时 golden 180 场逐场一致、参数指纹不变、C0 / C1 的并排调用序列测试仍逐位相同（实现提交的验收条件）。
`preStepLegacy` 与 `EXECUTOR_SWITCH.legacy` 保留不动。默认值与 golden 只在 C4 通过后切换一次（路线报告 §10）。

**停止条件**（任一触发即停止并报告，不扩展参数网格）：
1. C2-P 三个候选臂在筛选集上都未达到 P1 → 允许一次带根因的重新预注册（新文件、新提交，门槛不变）；第二次仍不达标 → 放弃姿态预算改造，C 退化为“B + 执行层预算化”，报告写明低速失衡不在本阶段解决。
2. 任何臂违反 P6 的物理审计（NaN / 穿地 / 账本 / 确定性）且无法在预算内消除 → 该臂停止。
3. 预算使 120 Hz 物理步耗时相对 P0 增加 > 20%（CI 同机）→ 先优化，不能优化则停止。
4. 任何臂需要恢复或新增合成机制（stallBreak、stallRoll、程序化脱困、加速进动、强制朝向修正）才能通过 → 不允许，按失败处理。
5. 所有候选臂都违反 P7 → 停止并报告。

## 11. 边界：C2 不解决的问题

- C3：牵引的能量守恒与回合时长缩短、d_eff 的速度与能量冲突、N 的滤波选择；牵引公式、μ、N 在 C2 中一律不变。
- C4：持续接触与贴近状态下的战术重新决策；意图调制、跟进、切入、逼墙、连击链（C2 只报告）。
- 针尖镜像无牵引僵持（C1：僵持占回合时间 36%，磐盾镜像 93%）——不是姿态问题。
- 合成刮地（C2 期间保持不变）、碰撞体几何（磐盾轴杆比针尖宽，只测量其影响）。
- P2.1、P2.3.1 两个现有失败测试；渲染画质；真机性能。
- 不恢复 stallBreak、stallRoll 或任何程序化脱困；执行层参数不写入 `BEY_TUNING` 与参数指纹。
