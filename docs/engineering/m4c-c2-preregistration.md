## 1. 实验目的与待验证假设

**目的**：判断“真实陀螺动力学 + 有预算的姿态恢复”能否替代现有合成 PD 与合成进动，产生自然的低速失衡、构筑间不同的失衡点和随转速变化的撞后恢复，同时不破坏全场景表现。

| 编号 | 假设 | 机制 | 检验 |
|---|---|---|---|
| H1 | 自转终结前出现可见的失衡过程 | 陀螺稳定性随 ω 下降而丧失；姿态恢复力矩 ∝ I_a·ω，低速时不足以对抗重力力矩 m·g·l·sin θ | E1a–E1d |
| H2 | 撞后恢复随转速降低而变慢 | 同样的横向角冲量 ΔL_⊥ 在低转速造成更大倾角（Δθ ≈ ΔL_⊥ / (I_a^phys·ω)），而恢复角速度有上限 K_ref | E4、S3 探针 |
| H3 | 四种构筑的失衡开始点不同 | 静力平衡估计 ω_hold = m·g·l·sin θ_c / (I_a^game·K_ref) 与陀螺临界 ω_c 因构筑而异（§3.4） | E6、M5 |
| H4 | 进动由重力与陀螺动力学决定 | 进动角速度 ≈ Ω_p = m·g·l / (I_a^phys·ω)，方向与重力力矩一致 | M1、M2 |
| H5（副作用，只观察） | 牵引方向改由实际倾斜方位决定后，方向变化变慢、运动形态改变 | 合成进动 ≈ 4 rad/s → 真实进动 ≈ 0.8 rad/s（C1 换算） | M7 + 全场景闸门 |

## 3. 物理公式与参数定义

### 3.1 两套惯量（必须区分）

| 符号 | 代码 | 含义 | 在 C2 中的用途 |
|---|---|---|---|
| **I_a^game** | `spec.spinInertia` | 游戏层自转惯量（零件质量 × 半径² × 外缘系数之和） | 自转规则、账本、能量扣除、**姿态预算** |
| **I_a^phys** | `massProps.Ia` | 刚体绕转轴的解析惯量（碰撞体） | B0 陀螺项（`gyroStep`）、进动理论值 Ω_p、ω_c |
| **I_t^phys** | `massProps.It` | 刚体绕质心的横向惯量 | 力矩 → 横向角速度换算 Δω_⊥ = τ·dt / I_t^phys；横向动能 |

I_a^game / I_a^phys：烈刃 1.01、森衡 1.09、磐盾 1.18、紫曜 1.50（C1 §2）。因此姿态预算按 I_a^game 计算时，刚体实际得到的转轴角速度是指令值的 I_a^game / I_a^phys 倍（§3.3），诊断逐台记录。

### 3.2 其余符号

ω = 游戏转速 `spin`（rad/s），ω_s 为带符号转速；û 为转轴；θ_v = acos(û·ŷ)（相对竖直）；θ_rel 为相对当地地面法线（tiltDrive 用）。
m = 刚体质量（= 零件总质量）；g = 20；l = comY − ρ（质心高于接地球心，ρ = `bit.contactRadius`）。
重力力矩 τ_g = m·g·l·sin θ_v；真实进动 Ω_p = m·g·l / (I_a^phys·ω)；陀螺临界转速 ω_c = 2·√(m·g·l·I_t^phys) / I_a^phys。

| 构筑 | m | l | I_a^game | I_a^phys | I_t^phys | ω_c（rad/s，≈ ω₀ 的比例） | Ω_p 在 C1 中位转速下（换算，待实测） |
|---|---|---|---|---|---|---|---|
| 烈刃 | 4.40 | 0.270 | 0.463 | 0.457 | 0.294 | 11.6（0.09） | ≈ 0.83 |
| 森衡 | 4.55 | 0.264 | 0.538 | 0.494 | 0.300 | 10.9（0.08） | ≈ 0.76 |
| 磐盾 | 5.10 | 0.350 | 0.597 | 0.507 | 0.322 | 13.4（0.10） | ≈ 0.87 |
| 紫曜 | 4.95 | 0.329 | 0.731 | 0.486 | 0.314 | 13.2（0.10） | ≈ 0.80 |

（C1 的 Ω_p 用的是 I_a^game；上表按 I_a^game / I_a^phys 换算到刚体口径，属推算，C2 诊断实测。）

### 3.3 C2 候选姿态律（实验臂 C2-a / b / c 共用，只有 K_ref 不同）

1. **锥**：θ_c = `bit.drift`（零件设计倾角，烈刃 0.20、森衡 0.16、磐盾 0.03、紫曜 0.05），相对**竖直**（与重力进动同一参照，与现有 PD 目标同一参照）。
2. **只纠正超出锥的倾角**：e = max(0, θ_v − θ_c)；t̂ = 垂直于 û、在 û 与 ŷ 所在平面内指向 ŷ 的单位向量。不控制方位角——**不设定、不加速、不减速进动**。
3. **指令转轴角速度**：Ω_cmd = min(k·e, K_ref)，k = 10 s⁻¹（= 现有 uprightStiffness / uprightDamping，现有 PD 的平衡比；固定，不是实验变量）。
4. **力矩**（陀螺极限下 L̇ = τ ⇒ û̇ ≈ τ / (I_a^phys·ω)）：τ_cmd = I_a^game·ω·Ω_cmd·t̂。
5. **预算**：|τ_cmd| ≤ c_g·I_a^game·ω·Ω_ref，**Ω_ref ≡ 1 rad/s（常数）**，所以 K_ref = c_g·Ω_ref 数值上等于 c_g。不使用 Ω_p 作 Ω_ref：I_a·ω·Ω_p = m·g·l 与转速无关，会使“恢复能力随转速下降”失效（C1 §3.3）。
6. **施加**：Δω_⊥ = τ_cmd·dt / I_t^phys（只改横向角速度；不调用 setRotation / setTranslation / setLinvel，不直接设定转轴）。
7. **不加阻尼项**：对 ω_⊥ 的阻尼会抵消真实进动；章动幅度作为测量量记录。
8. **能量**：横向动能增量 ΔKE_⊥ = I_t^phys·(ω_⊥·Δω_⊥ + ½|Δω_⊥|²) > 0 时从自转扣 Δω = ΔKE_⊥ / (η·I_a^game·ω)，η = 1，账本新增 `posture`；
   每步能量审计：姿态律带来的横向动能增量 ≤ 同步扣除的自转动能，违规次数必须为 0。（C1：现有 PD 的正功只占自转初始能量 0.1–0.7%。）
9. 新参数（k、K_ref、开关）放在 `EXECUTOR_TUNING` / 独立开关对象，不进 `BEY_TUNING` 与参数指纹；开关默认关。

| 磐盾 | 1.8 | 9.0（0.07） | 3.0（0.02） | 1.5（0.01） | 13.4 |

### 7.2 判定

### 7.3 选臂规则（多臂通过时）

## 8. 四种构筑的独立评价

- 每个构筑单独给出 M1–M7、E1a–E1d、E6、自灭、胜率，不用全体平均掩盖单一构筑。
- 单构筑 E1a 的判定只对“自转终结输方台次 ≥ 20”的构筑生效（C1 S1：烈刃 114、森衡 92、磐盾 19、紫曜 21）；不足 20 的构筑在确认集（约 2 倍样本）上判定，仍不足则标“样本不足，只报告”，并用 S2 / S3 的单台结果补充说明。
- **磐盾**：额外报告轴杆触地前 / 后的姿态变化与失衡开始点，以及轴杆接地是否成为失衡的主导机制（M6）。若磐盾的失衡几乎全部始于轴杆触地，报告中写明“磐盾失衡由碰撞体几何决定”，不归因于姿态律。

## 9. 回滚方法与停止条件

**回滚**：C2 全部改动在独立开关之后，默认关闭；默认关闭时 golden 180 场逐场一致、参数指纹不变、C0 / C1 的并排调用序列测试仍逐位相同（实现提交的验收条件）。
`preStepLegacy` 与 `EXECUTOR_SWITCH.legacy` 保留不动；关闭开关或回退实现提交即可恢复。默认值与 golden 只在 C4 通过后切换一次（路线报告 §10）。

**停止条件**（任一触发即停止并报告，不扩展参数网格）：
1. 筛选集上 C2-a / b / c 与 C2-B0 都未达到 E1（P1）→ 允许一次带根因的重新预注册（新文件、新提交，门槛不变）；第二次仍不达标 → 放弃姿态律改造，C 退化为“B + 执行层预算化”（只做 C3、C4），报告写明低速失衡不在本阶段解决。
2. 任何臂出现能量审计违规且无法在预算内消除 → 该臂停止。
3. 姿态律使 120 Hz 物理步耗时相对 C2-base 增加 > 20%（CI 同机）→ 先优化，不能优化则停止。
4. 任何臂只有恢复合成进动、按意图或转速加速进动才能通过 → 不允许，按失败处理。
5. 所有候选臂都违反 P6 或 P7 → 停止并报告。
