## 1. 通用规则

1. **种子集锁定**：每个实验的种子公式写在本文件和诊断脚本里；结果出来后不改种子、不挑场次、不追加样本。
2. **对照臂**：每个实验都有 base 臂（当前参数），与实验臂使用同一套种子。
3. **统计**：胜率报告 Wilson 95% CI；两臂之差报告 Newcombe（Wilson 混合）95% CI；终结分布用卡方检验（自转 / 爆裂 / 出界 + 极限 / 平局 四类）。
4. **D4 掉速口径**（每个实验每个构筑，非镜像回合）：
   - 总掉速率 = Σ(发射转速 − 终局转速) / Σ回合时长（rad/s 每秒）；
   - 各来源（轴心衰减、空气、驱动、转向、轨道、刮地、咬合、重击 claw、Rapier 接触积分损失 / 增益、爆裂后）的每秒速率与占比；
   - 未解释残差 = |发射 − 终局 − (Σ损失 − Σ增益)| / 发射转速，报告中位 / P99 / 最大；
   - M5 的衰减差验收：任意两构筑总掉速率之比 − 1 ≤ 25%（本轮只报告现状，作为后续零件调参的验收项）。

## 3. E-A：重击击飞（D1 方案 A）

### 3.1 模型（代号 claw，`src/game/battle/clawStrike.ts`）

刀刃的爪在接触处构成倾斜的迎击面，接触法线偏离两心连线一个有效倾角 ψ。同向旋转的两刀刃在接触处的表面相对滑动约 2ωR（≈ 140 u/s），
它在倾斜法线上的分量使两者沿 n* 闭合——按刚体碰撞把一部分自转动能换成双方分离的动量。

| 量 | 来源 |
|---|---|
| 是否接触 | Rapier：两刀刃碰撞体之间的接触流形（法向冲量 > 0 或求解器接触距离 ≤ 0）；没有真实接触就没有重击 |
| 接触点 p、连线 u | 两质心水平连线、按两刀刃半径比例分点、两刀刃中心高度的平均 |
| 有效倾角 ψ | sin ψ = κ × bite × engage：bite = clamp(0.35 + 0.65·攻击值(出爪方) − 0.3·防御值(受击方), 0.15, 1)（现有的刀刃咬合描述：攻击值 = 爪的锋利程度，防御值 = 圆润刃缘的卸力）；engage = clamp((接近速度 + 0.4) / 5, 0.35, 1)（撞得越正咬得越深）；**κ 是唯一的标定系数**（实验臂） |
| 法线 n* | cos ψ·u + sin ψ·ŵ，ŵ = 出爪方刀刃在接触处的表面运动方向；两个方向（A 出爪 / B 出爪）都计算，取闭合速度更大者 |
| 质量 | Rapier `body.mass()` |
| 质心、惯量张量 | 由碰撞体（形状、质量、位置）解析计算（轴对称：轴向 Ia、横向 It）；CI 测试对照 Rapier 的实际冲量响应 |
| 恢复系数 e、摩擦 μ | 与 Rapier 刀刃碰撞体相同：e = 两刀刃 restitution 均值 × 0.4，μ = 两刀刃 friction 均值 |

计算（物理步之后的速度；两心连线方向的普通碰撞 Rapier 已经处理，这里只补倾斜面产生的部分）：

1. 闭合速度 v_c = (v_A + ω_A × r_A − v_B − ω_B × r_B) · n*；v_c ≤ 0（正在分离）→ 不发生。
2. 有效质量 K = 1/m_A + 1/m_B + (r_A × n*)·I_A⁻¹(r_A × n*) + (r_B × n*)·I_B⁻¹(r_B × n*)；法向冲量 J_n = (1 + e)·v_c / K。
3. 库仑摩擦：施加 J_n 后接触点的切向相对速度 v_t；J_t = min(μ·J_n, |v_t| / K_t)，方向与 v_t 相反（不会使滑动反向）。
4. 冲量 J = J_n·n* + J_t·t̂ 作用在同一接触点：B 受 +J，A 受 −J。

物理约束（按构造保证，并逐次审计）：线动量与对任意点的角动量守恒（同一点、等大反向）；单约束牛顿碰撞（0 ≤ e ≤ 1）
加不反向的库仑摩擦，动能不增——每次重击先用解析速度计算 ΔKE，若 ΔKE > 1e−9 × KE（数值容差）则不施加并计数（理论上永不触发）。
攻击方的转速代价由角冲量自然产生（r × J 经惯量张量作用在角速度上），不另加扣除；账本新增 `claw` 分项（按施加前后的角速度在转轴上的投影精确记录）。

claw 臂替换现有咬合冲量（`resolveSmash` 的 jn / jt 与额外的 spinLoss 掉速），只保留撞击反馈事件（强度按 claw 冲量折算的相对速度变化）。
默认关闭（`CLAW_EXPERIMENT.enabled = 0`），关闭时与现状逐位一致（golden 不变）。

- 臂：base（现有咬合模型）、claw κ = 0.05 / 0.1 / 0.2 / 0.3；
- 种子：签名矩阵 4 × 4 × 20，seed = 20000 + 1000·p + 100·r + i（与 M5a G / H / J 相同，便于对照）；

  最大水平速度、物理审计（能量增加被拒的次数、最大相对 ΔKE、动量残差）、D4 掉速口径（含 claw 分项）；

  若没有一臂进入 13–28%，报告方向与原因，不进入 E-A2，在此基础上调整筛选范围（新的筛选同样先写进本文件）。

- 采用条件（全部通过）：

| 编号 | 条件 |
|---|---|

| C3 自灭 | 自灭占比 ≤ base + 5 个百分点（v2.0 §6.7 口径） |
| C4 攻击型获胜途径 | 烈刃非镜像胜率高于 base（两臂之差的 95% CI 下限 > 0），且烈刃的胜局中出界 / 极限 / 爆裂合计 ≥ 50% |

- 平衡目标（默认对局 45–55%、克制链 55–65%）**不是**本实验的采用条件：机制成立后，在新机制上重新筛选零件参数（含针尖 spinDecay ↑）并按功效样本确认（E-P，规则届时先写进本文件）。
- 采用后：并入正式参数，重新生成 golden，真机手感确认待 IPA 授权。
