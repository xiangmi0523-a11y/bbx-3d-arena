## 2. 惯量契约（R12，`tests/diag/inertia.diag.ts`）

64 种组合中 52 种游戏层 `spinInertia` 与 Rapier 主惯量 Iy 相差 > 5%：范围 −1% … +56.5%，均值 +19.3%。
原因是建模口径：游戏层 Blade / Disc 用 m·r²·rimWeight（0.45–0.8），Rapier 圆柱按均匀实心 ½·m·r²；轴心两边也不同口径。
按 R12：v1 一律以游戏层标量为准（衰减、自稳、撞击掉速），Rapier 张量只作参照；两套口径同时存在的位置已写入《物理状态所有权清单》（Rapier 接触对自转的改变按 Rapier 张量，游戏层衰减按标量）。切换完整张量列为后续研究。

## 3. 接触段冲量分布（爆裂标定输入，`tests/diag/burst-calib.diag.ts`）

场景：180 场中的自然对局 150 场（去掉受控摆放 CTRL 与针尖低功率 NNPOW）；当前物理（M2 改动前）。全部 150 场为自转终结。

| 指标 | 值 |
|---|---|
| 接触段数 | 1120（每回合 7.5 段） |
| 段冲量 Σ（N·s）P10 / P50 / P75 / P90 / P99 / 最大 | 1.0 / 10.0 / 18.0 / 26.1 / 44.8 / 50.4 |
| 段时长 P50 / P90 / 最大 | 0.008 / 0.042 / 0.575 s（大多数段只有 1 步） |
| 按撞击档位的段冲量中位数：无撞击事件 / 轻 / 中 / 猛 | 0.86 / 3.3 / 8.8 / 19.3 |
| 重击段（Σ ≥ 2 × 中位）中位数 | 26.1（226 段） |

**实测法向冲量能区分轻擦与重击**（中位数 3.3 → 19.3，单调），作为爆裂唯一输入成立。

### k 扫描（爆裂发生前物理与不开爆裂完全相同，以下为精确离线计算，lock / burstGuard 取 v2.0 初值）

| k | 0.00283 | 0.00317 | 0.00356 | 0.00399 | 0.00448 |
|---|---|---|---|---|---|
| 爆裂终结占比 | 2.7% | 11.3% | 28.0% | 44.0% | 57.3% |
| 爆裂时刻中位 | 22.5 s | 9.7 s | 8.7 s | 7.6 s | 7.3 s |

发现：

1. **v2.0 的两条标定规则互相矛盾**。按“单次重击段让 lock 0.50 的陀螺 Δstress 0.10–0.15”得到 k ≈ 0.0019–0.0029，对应爆裂终结只有 0–3%；要达到 §5.4 的 15–25%，k 需约 0.0033–0.0035，此时单次重击段对 lock × burstGuard = 0.25 的紫曜 Δstress ≈ 0.36。M2 以**终结分布目标**为准定值（它是验收标准），并报告对应的单段增量。
2. 爆裂占比随 k 变化很陡（0.0032 → 0.0036 从 11% 到 28%）：一回合内累计冲量的分布比较集中。M2 必须在换位后的签名构筑对局上重新标定，不能直接沿用本表。
3. 本表是 M2 物理改动（R2 / R3 / R8）之前的数据，只作为量级参考。
