## 3. 测试与验证体系

1. **CI 每次推送**：类型检查 → 全部单元测试 → 180 场固定种子全量回归（golden）→ 网页构建；诊断任务按 `scripts/ci-diag.sh` 运行实验并上传结果。
2. **确定性回归 ≠ 平衡结论**：golden 只回答“行为变没变”；胜率、分布结论一律用功效表样本量（10 个点差每组约 390 场）+ Wilson 95% CI，实验前写明效应量、样本量、种子集与采用 / 回退规则。
3. **行为变化的纪律**：任何改变物理 / AI / 规则的提交，在提交说明里列出变化原因与影响面，CI 先证明“只有预期的场景变化”，再重新生成 golden；改名、重构类提交必须证明四通道哈希不变。
4. **禁令守护**：不引入 stallBreak / stallRoll / 通用程序化脱困 / 瞬移 / 无约束速度注入 / 强制朝向 / 脚本假碰撞；`motion.test` 已有“发射后只施加有上限的冲量、不设置速度或位置”的检查，继续保留并扩展。
5. **不以单元测试代替体验验收**：每个里程碑附固定种子录像 / 截图与指标表；体验结论由真机验收给出。

### 6.1 M5a 结论（2026-11-11，`docs/engineering/m5-ledger-report.md`）

- E7 账本闭合（残差最大 0.14%），S1 遗留的 E7 验收完成。
- 掉速主因不是 spinDecay（只占 12–21%）→ “衰减差封顶”不靠调 spinDecay 实现（来源分解见下方 I 部分；最初“Bit 倾斜接地摩擦”的解释已被 H / I 推翻）。
- R6 口袋加宽、R7 墙恢复 0.2：按预注册规则均**不采用**（击飞需要约 8.4 m/s 才能爬出碗沿，口袋加宽只增加自灭）。
- 平衡杠杆筛选（G 部分）：五个杠杆都没有动摇磐盾（94–98%）；咬合接近速度项方向错误（爆裂 20% → 8%），放弃。
- **中心平台取消（centerFlat 0）消除了针尖僵持**（针尖镜像无接触低速段 40–55 s → 4–9 s，全部自然结束），平衡几乎不变——这是 M4 的根因级候选，
  但属于竞技场几何改动，**等 Huang 确认后才进入确认实验**。
- 零件参数筛选（H 部分）：**针尖 spinDecay ↑ 让“耐克防”第一次出现**（2.0 → 紫曜 20 : 17 磐盾；3.0 → 26 : 12）；圆球 spinDecay ↓、王冠 rimWeight ↑、Bit 摩擦都无作用；
  攻 → 耐、默认对局没有零件杠杆能改善（攻击型缺有效进攻手段，是机制问题）。Bit 摩擦几乎不影响接触损失 → 账本 §2 的机理解释被推翻，I 部分做来源分解。
- 接触损失来源分解（I）：一半来自不到 1% 时间的刀刃相撞（双方对称），另一半是宽 Bit 的滚动移动（与摩擦系数无关）。
- 碗面深度筛选（J）：降低碗沿几乎只增加自灭，**不采用**。攻击型缺的是“撞击转化为终结”的机制，方案 A / B / C 见 `m5-ledger-report.md` §9，**等 Huang 选择**。

### 6.3 M5b 第一轮结果（2026-11-11，`docs/engineering/m5b-results.md`）

- D3 已实施（PR #11），golden 未变化（180 场逐场一致）。
- **E-CF 中心平台：按预注册规则不采用**——僵持大幅缓解（针尖镜像最长低速段中位 79 s → 9 s），四构筑胜率、自灭、时长都在门槛内，
  但“2 s 内重接触率”只提高 5.8 个点（门槛 10），且终结分布显著改变（爆裂 18% → 25%，p = 0.001）。留到 M4 重新预注册。
- **D1 重击模型 claw 已实现并通过物理审计**（约 1.8 万次重击：能量从不增加、线动量残差为单精度量级；解析质量属性与 Rapier 实际响应一致），默认关闭。
  E-A1 / E-A1b 筛选：重击让“攻克耐”第一次成立（κ 0.05：烈刃 26 : 14 紫曜，靠爆裂），但击飞最多 3.1%——大重击的方向与口袋方位无关（19% / 26% = 口袋占比），
  按规则不进入 E-A2，结论是**击飞需要 AI 主动把对手撞向口袋**，转入 M4。
