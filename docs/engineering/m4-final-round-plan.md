## 1. 第一阶段：接触几何（C1）

**假设 H1**：平底的两个异常都来自“平面 + 边缘”接地几何，而不是尺度参数：
(a) 圆角圆柱只要稍有倾斜，接地点就跳到轮缘（偏移 d ≈ R），轮缘纯滚动且质心几乎不动的状态（原地滚边，横向角速度 ≈ ω_s·d / l）是它的稳定吸引子；
(b) 平面底在倾角 < atan((R − b)/(comY − b)) ≈ 0.2–0.3 rad 内静稳定，转速耗尽时会立着停，不会出现低速失衡。
把接地面换成**微凸球冠**（球半径 ρ，底面边缘半径仍为 contactRadius）后：接地点偏移 d = ρ·sinθ 随倾角连续变化，没有“跳到轮缘”的几何；
当 ρ < comY 时重心高于球心，直立在零转速下静不稳定，失衡必须靠陀螺效应维持，转速低于临界值时自然倒下。
同时 ρ 远大于球头（0.09）与针尖（0.045），倾斜时 d 更大、牵引更强，攻击型与耐力型的差异来自几何本身。

**唯一变量**：平底 / 橡胶轴心（gear-flat、rush-rubber）的接地碰撞体形状。球头、针尖不变。

| 臂 | 平底 / 橡胶接地形状 |
|---|---|
| C1-0（对照） | 圆角圆柱，边缘倒圆 0.05（= A2 `g80-s1.4-b0.05`） |
| C1-a | 微凸球冠，ρ = 0.25（静不稳定裕度大：l = comY − ρ ≈ 0.15–0.17） |
| C1-b | 微凸球冠，ρ = 0.35（更接近平底：l ≈ 0.05–0.07） |

实现：`roundConvexHull`（球冠点集 + 顶面圆，倒圆 0.01，倒圆后的外形就是半径 ρ 的球冠），底面最低点仍在轴心原点；质量属性仍按同尺寸圆柱计算（轴心质量占比小，形状差异对 I_a / I_t / 重心的影响 < 1%，在报告里给出实测值）。

**记录**（逐子步，按转速比例分档汇总，并输出每台的时间序列）：接地点离转轴距离 d、接地法线与竖直 / 场地法线的夹角、接地点滑移速度、
轴心接地占比、接地摩擦对自转轴的力矩（单台里没有其他接触时 = I_a × 账本里 Rapier 接触掉速率；有非轴心部件触地的步单独计）、
能量（自转动能、横向转动动能、平动动能、势能，每档的变化量）、姿态（相对地面倾角、进动角速度、摇摆幅度、横向角速度）、原地滚边时长、失衡过程、触地（非轴心部件碰地面）与停转。

**通过标准（每臂独立判定，四组必须全部满足）**：

- **C1 接地异常消除**：36 台里原地滚边（比例 ≥ 0.3 时连续 ≥ 2 s 速度 < 0.3 u/s 且横向角速度 > 0.15 ω_s）最长 < 2 s；平底 / 橡胶构筑（烈刃、森衡）在比例 0.3–0.9 段轴心接地占比中位 ≥ 0.8（不再跳着走）。
- **C2 自然低速失衡**：四个签名构筑各自至少 4 / 6 台的终结有失衡过程（与 B 阶段 E1 同一定义）；24 台失衡过程中位 1–4 s；
  比例 > 0.3 时不出现持续 ≥ 0.2 s 的超出倾角 ≥ 0.25 rad（发射后 1 s 不计）——即失衡出现在低转速，不是开局就倒。
- **C3 进动 / 摇摆随转速下降而增强**：至少 3 / 4 个签名构筑的进动角速度中位在 0.2–0.3 档大于 0.6–0.7 档（陀螺物理的必要条件，用来排除“靠数值抖动倒下”）。
- **C4 四种构筑合理差异**：烈刃、森衡的中段（比例 0.3–0.7）平均速度都 ≥ 1.5 × 磐盾；烈刃、森衡中段半径中位 ≥ 0.25 R；烈刃、森衡 E2a（0.5–0.6 档 / 0.8–1.0 档速度）≥ 0.65。

只报告、不判定：寿命（第二阶段的题目）、E3、触地时刻、能量分解。

**判定**：C1-a、C1-b 各自判定。都通过时取 36 台原地滚边总时长更短的一臂，再看 E2a 最小值更高者。
**两臂都不通过 → 触发停止条件**：不跑第二阶段，物理尺度路线停止，转入 M4-C 整体技术路线评估。

## 2. 第二阶段：耐力型损耗（C2，仅在第一阶段有臂通过后运行）

**假设 H2**：耐力 / 防守型（球头、针尖）在 A 路线里寿命短，是因为倾斜进动时轴心接触点离转轴的偏移变大，接地滑动摩擦对自转的力矩随之变大，
而不是来自部件碰地或碰撞。这一阶段先把损耗来源拆开量清楚，再只改一个变量：球头 / 针尖的地面摩擦。

**固定**：第一阶段选中的接触几何与对照组的全部其余设置。
**唯一变量**：球头、针尖轴心（dome-ball、needle-point）的摩擦系数倍数 k ∈ {1（对照）, 0.5, 0.25}；平底 / 橡胶不变。

**损耗分解**（每台、每个转速档，账本残差 ≤ 1%）：
自转损耗按来源记——轴心基础衰减（合成）、空气阻力、轴心接地摩擦（只有轴心碰地面的子步里的 Rapier 接触掉速）、
倾斜接地损耗（有非轴心部件碰地面的子步）、碰撞损耗（与对手接触的子步）、同一子步多种接触同时存在的（单列“混合”）；
平动能另记滚动阻力（合成滚阻做的功）与滑动摩擦（接地摩擦做的功）。碰撞损耗需要对局：在 16 种对阵 × 4 种子的小矩阵里量，
前提是对局里的转速尺度 1.4 先实现并通过单元测试（所有与转速绝对值比较的阈值同乘 1.4，k = 1 时与第一阶段单台一致）；做不到就写明“碰撞损耗未测”。

**通过标准**：
- **D1 分解可信**：账本残差 ≤ 1%，“混合”占比 ≤ 10%。
- **D2 来源合理**：紫曜、磐盾在比例 > 0.3 时，倾斜接地损耗占自转损耗 ≤ 20%，轴心接地摩擦 + 基础衰减 + 空气 ≥ 70%（损耗来自接地点而不是部件刮地）。
- **D3 寿命**：紫曜、磐盾单台寿命中位 ≥ M4-A 的 60%（51.6 s / 74.3 s）——只在 D1、D2 同时成立时才算数，不能单靠寿命判通过。
- **D4 不破坏第一阶段**：选中几何的 C1–C4 全部仍然成立。

**停止条件**：没有 k 同时满足 D1–D4 → 物理尺度路线停止，转入 M4-C 整体技术路线评估。
