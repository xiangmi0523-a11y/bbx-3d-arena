# M4 实验计划（预注册）：陀螺战斗生命周期与 AI 战术

> 2026-11-11 预注册，分支 `v2/s4-motion-ai`。依据：Huang 的 M4 修正指示（2026-11-11）、`m4-reference-battles.md`（录像）、`m4a-baseline.md`（基准）。
> 本文在任何 M4-B / C / D 实验运行之前提交；之后只追加结果，不改已登记的规则。改规则必须新开一节、写明原因，并且不能用改过的规则解释改之前跑出的数据。

## 0. 目标与边界

**目标**：建立完整、自然的生命周期——稳定运动 → 接触与能量消耗 → 失衡与摇摆 → 触地或终结；再让 AI 在物理约束内利用它（外圈切入、追击、连续接触、逼墙、利用对手失衡）。

**硬边界**（全部阶段）：

- 运动变化只能来自真实的力矩、摩擦、惯量、重心和接触；不直接注入速度、不强制修改朝向、不瞬移、不人为制造失衡、不脚本化碰撞或追击。
- 不恢复 `stallBreak`、`stallRoll` 或任何通用程序化脱困；现有的死亡摇摆脱离（`wobbleBreak`）属于程序化干预，在 B4 评估移除，期间不新增同类机制。
- 30% 转速阈值只作为待验证假设，不写进任何物理公式；各构筑的失稳点由刚体参数与接地形状决定，实测后报告。
- 新机制全部放在实验开关后，默认关闭（golden 180 场逐场不变）；采用后再并入默认值并重新生成 golden，旧路径在结论出来前不删除。
- 固定种子、可重复；每个实验臂的代码、规则、结果都留在仓库与 CI 日志里。不合并 main、不构建 IPA、不部署、不发布。

**数据标注**：【模拟实测】【录像提取】【推断】，与 M4-A 报告相同。

## 2. 测量口径（代码：`tests/diag/m4.metrics.ts`）

- **倾角**：tiltV = 转轴与竖直方向夹角；tiltN = 转轴与所在位置地面法线夹角。**基准倾角** = 转速比例 > 0.6 的自由运动段 tiltN 中位数；**超出倾角** = tiltN − 基准倾角。
- **自由运动**：不在接触中、距上次接触 ≥ 0.3 s、发射后 ≥ 1 s。按转速比例 0.1 一档统计平移速度、半径、tiltN、摇摆（tiltN 与 ±0.25 s 滑动平均之差）、横向角速度、进动（转轴方位角变化率）、触地占比。
- **触地**：Bit 接地球以外的碰撞体（轴杆 / Ratchet / Blade）与地面有求解器接触（距离 ≤ 1 mm）或接触冲量。
- **接触段**：两台之间法向冲量 > 0，间隔 ≤ 0.1 s 合并（与爆裂同一定义）。
- **终结过程**（只对“终结”判定的回合）：从发起时刻往回找输方超出倾角 ≥ 0.25 rad 的连续段（允许 < 0.2 s 回落）的起点 t*；过程时长 = 发起 − t*（窗口 8 s）；
  倾角上升 = 过程内时间与超出倾角的 Spearman ρ；另记最后 3 s 触地、最后一次接触距结束、最后一次接触时输方超出倾角、赢方结束时超出倾角。
- **撞后恢复**：接触段开始后 0.4 s 内超出倾角升高 ≥ 0.1 rad 的事件，从峰值回到“撞前 + 0.03 rad”的时间（1.5 s / 下一次接触 / 回合结束为截尾），按撞击时转速比例分档。
- **战术**：利用失衡（一台超出倾角越过 0.25 且之前 ≥ 1 s 低于后，1.5 s 内开始接触）、外圈切入（接触段开始前 0.05 s，接近更快的一方半径比另一方大 > 0.3）、
  逼墙（被撞方 0.6 s 内从 < 4.4 到达 ≥ 4.4）、连击链（接触段间隔 ≤ 1.5 s，≥ 3 段）。
- **阶段**：回合三等分（≥ 15 s 的回合）；最后 10 s / 中段接触频率（≥ 20 s 的回合）。

## 4. M4-B：物理生命周期（分步，每步一个变量族）

工程前提——**B0 陀螺项**（开关 `GYRO_EXPERIMENT.enabled`，默认 0）：在 `preStep` 里补上 Rapier 缺的陀螺项 −ω × Iω。
对称刚体在转轴分解 ω = ω_s û + p 下，缺失部分等于把横向角速度 p 绕转轴旋转角度 ((I_a − I_t) / I_t) · ω_s · dt（用精确旋转，无条件稳定、不改能量、不改 |p|）。
I_a、I_t 取碰撞体的解析质量属性（`massProps`，爆裂后按去掉刀刃的值）。B0 通过下列单元测试才进入 B1：

- T1 无重力自由刚体：2 s 内角动量相对漂移 < 0.1%、动能漂移 < 0.1%（Rapier 单独 3.8%）。
- T2 重陀螺（球铰支点，无摩擦）：ω = 8 ω_c 时进动角速度与 m g l / (I_a ω) 相差 < 10%；ω = 1.5 ω_c 时 3 s 内倾角 < 2 倍初值；ω = 0.6 ω_c 时 3 s 内倾角 > 1 rad。
- T3 场地内（四构筑，自稳 PD 关闭）：无 NaN、无穿地、账本残差 ≤ 1%。

实验臂（每步在前一步被采用的基础上叠加；每步先筛选 20000 × 20 + 单台，通过后用确认集 60000 × 40 复核）：

| 臂 | 改动（开关） | 主要检验 |
|---|---|---|
| B1 物理自稳 | 陀螺项开；自稳 PD 关；牵引方向取实际转轴相对地面法线的倾斜方向（不再用合成进动相位）；显式牵引保持现有大小公式，再乘接地点偏移比例 min(1, sin θ_rel / sin drift)*；战术意图的进动调制暂停（AI 只保留决策，没有执行器） | E1、E5、全程不退化（E2–E4、E6 报告） |
| B2 接地几何 | 平底 / 齿轮 / 橡胶轴心的接地碰撞体改为圆角圆柱（平底边缘真实着地，接地点离转轴的距离由形状决定）；显式牵引关闭，牵引只来自 Rapier 接地摩擦 | E2、E3、E4 |
| B3 刮地改真实接触 | 去掉合成刮地衰减（倾角 > 0.5 rad 的额外掉速），改由刀刃 / 棘轮与地面的真实摩擦掉速 | E1、账本 |
| B4 去掉程序化脱离 | `wobbleBreak` 关、`edgeGrip` 关 | E5、自灭 |

\* 2026-11-11 B1 运行前补充（实现 B0 时发现）：去掉 PD 后转轴可能接近竖直，接地点离转轴的距离 ∝ sin θ_rel，竖直时物理上没有牵引；不乘这个比例的话，几乎竖直的陀螺会在一个近乎随机的方向上得到满额牵引。比例在 θ_rel ≥ 轴心自然倾角时为 1，即不改变现有公式在正常倾角下的大小。

**判定规则**：B1 需要 E1、E5 与全程不退化全部通过；B2 起再加 E2、E3（B1 的牵引大小仍按转速比例，E2 / E3 在 B1 只报告）。
筛选集通过后在确认集上同样通过才采用；E4、E6 必须报告，E4 不过时写明原因但不单独否决。
没通过的臂：报告失败的指标与根因分析，不在同一臂上调参“凑”指标；若要改参数，另开一节预注册新臂（写明参数范围与理由）。
任何需要“规定倾角 / 规定失稳点”的退路方案都属于人为制造失衡，不做；如果物理臂都不通过，带着数据回报 Huang 再定。

**风险（预先登记）**：去掉合成进动后，“花瓣轨迹”与 AI 瞄准会暂时消失或变弱，直到 M4-C 建立物理执行器；B1 / B2 的对局胜率与终结分布会明显变化，这一阶段不以平衡为目标（M4-D 处理）；
120 Hz 下快速章动（约 1.5 × 转速）分辨不出，可能表现为高频抖动——T2 / T3 会暴露，必要时把物理步改为 240 Hz（作为 B0 的一部分重新验证）。

## 5. M4-C：AI 战术（物理基准明确后）

- **执行器**：在 B 阶段采用的物理模型上，AI 只能通过有上限、按转速付费的力矩改变转轴倾斜方向（陀螺效应决定实际响应），或在决策层选择何时切入、何时脱离；
  不直接设定速度、位置或朝向。执行器上限候选（预注册筛选网格）：|τ| ≤ c · m g l，c ∈ {0.25, 0.5, 1.0}。
- **战术**（每次接触前后都按对手当前状态与实际位置重新决策，不是固定连招）：外圈切入（从坡上高处切下）、追击失衡对手、连续接触（对手超出倾角仍高时再次切入）、逼墙（选择让对手退路指向墙 / 口袋的切入角）。
- **指标与门槛**：利用失衡 ≥ 45%（基准 23.5%）；外圈切入 ≥ 40%（23.6%）；逼墙 ≥ 5%（1.2%）；连击链 ≥ 1.0 条 / 回合（0.62）；
  最后 10 s / 中段接触频率中位 ≥ 1.5（1.0）；出界 + 极限 5–20% 且自灭 ≤ 基准 + 3 个百分点；E1、E2、E5 不退化。
- **审计**：每步记录执行器力矩，超过上限的步数必须为 0；AI 的任何输出都不能直接写速度 / 位置 / 朝向（代码审查 + 单元测试）。

## 6. M4-D：集成与重新平衡

- 在新物理 + 新 AI 上重跑重击模型筛选（κ ∈ {0, 0.05, 0.1, 0.2}，E-A1 口径），选臂规则沿用 `m5b-experiment-plan.md` §3。
- 评估四构筑：胜率、D4 掉速口径、击飞、爆裂、自灭、回合 / 比赛时长。门槛：每个签名构筑非镜像胜率 30–70%；相克三角每条（攻 > 耐、耐 > 防、防 > 攻）有利方 ≥ 55%；
  终结分布 自转 ≥ 40%、爆裂 10–30%、出界 + 极限 8–25%；自灭 ≤ 5%；回合时长中位 15–35 s。
- 不能只看击飞率：任何构筑在基准里已有的胜路（例如耐力型的自转胜、防守型的爆裂胜）不能因为调整而整体消失（该终结类型的胜场不低于基准的一半），除非有新的合理胜路替代并写明。
