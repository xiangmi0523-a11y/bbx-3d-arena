# M4-C 技术路线决策报告

> 2026-11-12，分支 `v2/s4-motion-ai`（HEAD 5cea485）。本报告只做评估与最小验证设计，**不改代码、不开实现 PR**。
> 依据：当前代码（`BeyPhysics.ts` 754 行、`motionIntent.ts` 494 行、`BattleSystem.ts` 694 行、`ContactService.ts`、`gyro.ts`、`clawStrike.ts`、`burst.ts`）；
> M4-A 基准（`m4a-baseline.md`）、M4-B 全部数据（`m4-results.md`：B0、B1、B2、探针 Q1–Q5、A1、A2、最后一轮 C1）、M5b（`m5b-results.md`）、M2/M3/M6（`m2-m3-m6-report.md`）、M7（PR #13）。
> 标注：【实测】= 本仓库 CI 数据；【录像】= `m4-reference-battles.md`；【推断】= 推理或待验证。

## 0. 结论

**推荐 C：分层混合架构**，并按“先拆接口、后换内容”的顺序落地：

```
战术层 MotionIntent（纯决策：目标、方式、时机；不碰物理）
        │  意图：heading、期望速度、姿态偏好、每次接触后的重新决策
        ▼
执行层 MotionExecutor（新模块，从 BeyPhysics.preStep 拆出）
        │  把意图换成有上限、有来源、有账本的力 / 力矩请求：
        │  牵引 ≤ μ_trac · N_实测；牵引速度 ≤ ω·d_eff（接地点表面速度）；姿态力矩 ≤ 预算；全部从自转能量扣
        ▼
物理层 Rapier 刚体 + 接触 + 碰撞 + 摩擦（+ 已验证的陀螺项 B0，作为第二个实验臂）
```

- **不选 A（纯刚体 + 辅助执行器）**：M4-B 三轮数据说明在本作尺度下，刚体接触给不出“倾斜着跑”的状态（平底：轮缘咬地 → 原地滚边、立着停；曲面：被摩擦扶正 → 没有牵引），
  要靠辅助执行器把它“撑”出来，执行器就成了运动的主体，A 实际上退化成 C，却额外背上 480 Hz（物理耗时 4–7 倍）与全局重标定。
- **不选 B（只改 AI）**：M4-A 的三个核心问题——牵引加速度 ∝ 转速比例（线性下降）、目标倾角随转速变小（越慢越直）、失衡过程 0.68 s——都写在运动公式里，AI 改不到。
  B 只能改善追击、切入、逼墙这类战术指标。
- **C 的关键**：现有合成模型里“不物理”的部分不是“有执行器”，而是执行器**没有物理来源和上限**（牵引 30 u/s² 与 g 无关、空中也有；自稳 PD 刚度 320 不随角动量变化；
  脱困与墙边借用咬合度）。C 保留执行器，但给每一项补上来源（接地法向力、接地点几何、自转能量）、上限与反作用，并把战术决策彻底移出执行层。

| `BeyPhysics.preStep` 第 1 部分（转速衰减 + 账本） | **保留**，账本加来源 | 账本闭合（残差 ≤ 1e-14【实测】）；新增“执行器牵引 / 姿态”两个来源 |

| 轴心牵引（driveAccel 30、driveSpeed 10、∝ 转速比例） | **改写**为执行层的有界牵引 | 线性下降的来源；无法向力门限 |
| 第 3 部分自稳 PD + 合成进动（stiffness 320，lean = drift × min(1, ω / 0.5ω₀)） | **改写**为有预算的姿态律 | “越慢越直”的来源；刚度与角动量无关 |
| 合成刮地 `scrapeDecay` | **退役（C2）**，改由真实部件触地 + 账本 | C1 实测紫曜倾斜时部件碰地掉速 5.5–15 rad/s²，物理本身已经有【实测】 |
| `wobbleBreak`、`edgeGrip`、`breakout`、`breakoutGrip`、`launchHold` | **退役（C4）** | 程序化脱困 / 借来的咬合度；由“每次接触后重新决策 + 执行层预算”取代 |
| `stallBreak`、`stallRoll` | 维持关闭，**不恢复** | 禁令 |
| 滚动阻力 `rollBase / rollFriction` | **保留**，并入执行层的耗散项 | 有真实对应（轴心滚动 / 滑动）；M2 R3 已定位它与针尖牵引的量级关系 |

接口变更集中在一处：`BeyPhysics.preStep` 里“意图 → 力”的那一段拆成 `MotionExecutor.step(state, intent, contact, dt) → {impulse, torque, spinCost}`，
BeyPhysics 只负责把请求施加到刚体并记账。这样执行律可以离线单元测试（与 `clawStrike.ts` 一样纯数学），也可以按开关整体回滚。

## 2. M4-B 数据对新架构的约束

| 数据 | 约束 |
|---|---|
| **接触几何**：圆角圆柱平底 → 原地滚边（最长 21 s）、17° 内静稳定立着停；球冠 → 被摩擦扶正，接地点偏移 d ≈ 0、滑移 0.05 u/s、中段速度 0.02 u/s（C1）【实测】 | ① 牵引**不能**指望 Rapier 的接地摩擦自然产生（两种几何只有两种坏结局）；② 碰撞体保持现有球头（支撑、碰撞、触地都正常，且 120 Hz 收敛）；③ 平底 / 橡胶的“攻击特征”放在执行层参数（μ_trac、d_eff），不放在碰撞体形状 |
| **120 Hz 平底不收敛**（高转速段 66–84% 的步离地）【实测】 | 不引入平底碰撞体就不需要 240–480 Hz；执行层必须用**实测 N** 做门限——离地 / 跳动时自动没有牵引，不会在空中“推” |
| **低速姿态**：物理临界转速 = 发射的 10–16%（g = 20），A2 把 g 提高后又出现原地滚边与寿命缩短【实测 / 推断】 | 不再改全局重力；失稳必须来自“姿态预算随转速下降、真实重力 + 接触力矩胜出”，临界点由各构筑的 I_a、m、l 与一个全局预算系数决定（不是统一 30%） |
| **姿态律方向**：M4-A 目标倾角随转速变小（“越慢越直”），失衡过程 0.68 s【实测】 | 新姿态律的稳定能力 ∝ 角动量 I_a·ω（陀螺刚度），低转速时可维持的姿态范围变小、摇摆幅度变大——方向与真实陀螺一致 |
| **耐力型刮地**：紫曜倾斜时非轴心部件碰地是主要掉速（中 / 低转速 5.5 / 15.1 rad/s²，大于轴心摩擦 3.3 / 0.9）【实测】 | 合成刮地可以退役，由真实部件触地产生“触地 → 急剧掉速 → 终结”；但姿态预算要让耐力 / 防守型在转速足够时保持在部件触地倾角以下，否则寿命被提前耗掉（A2：紫曜 15–42 s） |
| **尺度**：g = 20 时碗面能提供的向心加速度 g·tanα 在 0.43 R 处约 4.5 u/s²，录像攻击型（1.8 R/s、0.43 R）需要约 41 u/s²【推断】 | 外圈绕行的向心力**只能**来自牵引方向的持续偏转（真实陀螺里由进动带动，本作尺度下由执行层按意图偏转），且必须在牵引上限之内；这决定了 μ_trac 的量级（见 §3） |
| **A1 耗时**：480 Hz 物理每模拟秒 62–148 ms（120 Hz 21–51 ms，CI 机器）【实测】 | C 默认 120 Hz；执行层每步只做常数次计算，预算 ≤ 现有 preStep 的 +20% |

## 3. 执行层：有来源、有上限、有反作用

执行层只产生三类请求，每一类都写明来源、上限、衰减、反作用与账本：

| 请求 | 来源（物理解释） | 上限 | 随转速 | 反作用 / 账本 |
|---|---|---|---|---|
| **牵引力 F**（水平，作用在接地点） | 倾斜轴心与地面的滚动 / 滑动摩擦 | ‖F‖ ≤ μ_trac · N_实测（N 来自 ContactService 的轴心-地面法向冲量 / dt，离地为 0）；只在“沿 F 方向的速度 < ω·d_eff”时施加（接地点表面速度上限，不能把陀螺推得比轴心转得还快） | 转速高时上限由 μN 决定（与转速无关 → 高位保持）；转速低到 ω·d_eff 低于当前速度时自然失去推力（低位衰减）——这就是 Q5 里物理给出的“保持到约 0.3 才下降”的形状 | 反作用在静止的场地；做功 P = F·v 从自转动能扣：Δω = −P·dt / (η·I_a·ω)，η ≤ 1；账本来源 `drive` |
| **姿态力矩 τ**（垂直于转轴） | 本作缺失的陀螺刚度（B0 臂：由真实陀螺项提供）+ 轴心接地偏心产生的摩擦力偶 | ‖τ‖ ≤ c_g · I_a · ω · Ω_ref（陀螺刚度 ∝ 角动量）+ μ_trac · N · d(θ)；目标姿态只能在该轴心的倾角锥内（|lean| ≤ drift_max），不能指向任意朝向 | 刚度 ∝ ω：低转速时同样的扰动造成更大摇摆，重力力矩 m·g·l·sinθ 超过预算时**由真实重力把它放倒**——失衡不由脚本触发 | 对倾斜做的功从自转扣（`posture`）；阻尼项只耗散不注入 |
| **轨道冲刺**（齿轮构筑） | 齿轮与齿条啮合 | 现有 railDash / railMaxSpeed，加 N 门限 | 现有 | 现有 `rail` |

硬性守护（单元测试 + 物理审计，任何一项不通过就不进入实验）：
1. 发射后不调用 `setTranslation / setLinvel / setRotation`，角速度只经“施加冲量 / 写回 Rapier 结果 + 有界修正”（扩展现有 `motion.test`）。
2. 每步审计：执行层带来的平动 + 横向转动动能增量 ≤ 同一步执行层扣除的自转动能（η ≤ 1），违规次数必须为 0（与 claw 的能量审计同一做法）。
3. N = 0（离地、被撞飞、上墙）时牵引与接地力偶为 0。
4. 账本残差 ≤ 1%，新增来源单独列出。
5. 执行层不读对手状态——对手只出现在战术层；执行层只看自己的刚体状态、接触与意图。

**μ_trac 的说明**：在 g = 20 下，库仑摩擦 μ ≈ 0.2–0.5 给不出录像的速度（§2）。μ_trac 是按轴心标定的“牵引摩擦系数”（橡胶 / 平齿约 1–1.5、球头 0.3 左右、针尖 0.1 左右，最终值由实验标定），
相当于把现有 driveAccel × grip 换成“系数 × 实测法向力”。它是一个公开的游戏尺度参数，不伪装成真实摩擦；物理约束体现在：有法向力才有牵引、不超过接地点表面速度、做功全部从自转扣。

## 4. 攻击动作的实现方式（不注入位置、速度、朝向）

所有战术动作 = 战术层给出“期望”，执行层在 §3 的上限内用牵引方向去追：

| 动作 | 战术层（决策） | 执行层（实现） |
|---|---|---|
| 外圈绕行 | 选绕行半径与方向；按自己的牵引预算判断能否维持（预算不足就降半径，而不是硬撑） | 牵引方向 = 切向 + 指向圆心的分量，向心分量提供 v²/r；超出 μ_trac·N 时只能放大半径——轨迹由预算决定 |
| 切入 | 选切入角（现有 cutAngle 逻辑）、预测拦截点 | 牵引朝拦截方向；接近速度受 ω·d_eff 与 μN 限制，所以高转速时切入更猛、低转速时更钝 |
| 连续攻击 | **每次接触结束后重新决策**：看对手的倾角超出、转速比、位置（离墙 / 离口袋），决定再撞 / 绕开 / 拉开 | 每个决策只是新的期望方向；没有“连击脚本” |
| 追击 | 对手失衡（超出倾角 > 阈值）或被撞离中心时提高追击权重 | 同上；能否追上取决于自己的剩余预算 |
| 逼墙 / 撞向口袋 | 选择让“自己—对手—口袋 / 墙”接近共线的出击点（E-A1b 的结论：击飞取决于出击方向） | 先绕到外侧（绕行）再切入；冲击本身由 Rapier 碰撞 + claw 求解 |

## 5. 四种构筑的风格从哪里来

不写“类型脚本”，风格来自零件参数在执行层预算里的差异 + 战术层的偏好：

| 构筑 | 执行层预算（来自零件） | 战术偏好（MotionIntent 的 profile） | 预期风格 |
|---|---|---|---|
| 攻击（烈刃 · 橡胶） | μ_trac 高、d_eff 大 → 牵引强、速度上限高；I_a 较小 → 姿态预算掉得快 | 进攻倾向高，外圈绕行 + 切入，接触后多选再撞 | 前段快、外圈、频繁切入；后段失去速度上限，摇摆早 |
| 平衡（森衡 · 平齿） | 中等牵引 + 齿轮冲刺 | 利用轨道冲刺制造出击角度 | 中段外圈 + 冲刺切入 |
| 耐力（紫曜 · 球头） | 牵引低、接地偏心小 → 耗能慢；I_a 大 → 姿态预算持久 | 守中、闪避，后段对手失衡时才反击 | 中心附近缓慢游走，寿命长；后段利用对手失衡 |
| 防守（磐盾 · 针尖） | 牵引最低；质量与 I_a 最大 → 最难被撞歪 | 守中、贴身压制 | 中心不动，靠质量吸收冲击；需要防止“完全不动的僵持”（§7） |

M5b 已经测得磐盾非镜像胜率 96–97%【实测】，平衡由 M4-D 处理；C 的验收只要求风格差异与不退化，不在本阶段追胜率。

## 6. 转速下降、失衡、进动、摇摆、触地、终结

| 阶段 | 由谁产生 | 可验证的预期 |
|---|---|---|
| 稳定运动 | 执行层牵引 ≤ μN，未触及 ω·d_eff 上限 | 速度曲线在 0.5 档 / 满转速档 ≥ 0.65（E2a） |
| 接触与能量消耗 | Rapier 碰撞 + claw + 账本 | 掉速来源可分解（D4 口径） |
| 进动与摇摆 | 姿态预算 ∝ I_a·ω：同样的扰动在低转速时幅度更大、回正更慢；倾斜方向的旋转（进动）由姿态律给出、速率随转速下降而加快 | 撞后恢复时间 中 / 高 转速 ≥ 1.3（E4，M4-A 为 0.94）；0.2–0.3 档进动 > 0.6–0.7 档（C3 口径） |
| 失衡 | 重力力矩 m·g·l·sinθ 超过姿态预算时由真实重力放倒——临界点因构筑而异 | 失衡过程 1–4 s（E1b）、≥ 80% 的自转终结有失衡过程（E1a）、失衡开始转速比例与构筑相关而不是统一值 |
| 触地 | 真实部件（刀刃 / 棘轮）碰地面（C1 已能逐子步记录） | 终结前 3 s 触地 |
| 终结 | 部件触地后真实摩擦急剧掉速 → 停转 / 倾倒，回合裁判照旧 | 最后一击落在已失衡一方 ≥ 50%（录像 4 / 4） |

## 7. P2.1 撞击分档与 P2.3.1 双球头僵持

- **P2.1**：当前失败的断言是 `tiers.light > 0`（6 场里没有一次轻擦事件，CI 物理测试第 168 行）【实测】。
  撞击力度 = 冲量折算的相对 Δv / 12，低于 0.9 u/s 的接触算贴身摩擦、不产生事件；也就是说现在的接触要么是贴身磨（< 0.9），要么已经是中 / 猛（≥ 3.6）。
  推断原因：现有切入在“牵引满额 + 进动调制”下接近速度两极化，缺少低速擦碰【推断】。C 的处理：接近速度由“意图 + ω·d_eff 上限”连续决定，
  战术层有“试探 / 掠过”与“正撞”两种出击，自然产生 0.9–3.6 u/s 区间；**不改分档阈值**。验证：P2.1 原测试不改条件直接通过，另加诊断报告三档分布。
- **P2.3.1**：球头对球头最长僵持 15.5 s（门槛 1.6 s）【实测】。根因（M2 R3、M5b E-CF）：轴心牵引与滚动阻力量级相当、碗面中心平台回中梯度小、贴住后没有“重新决策”。
  C 的处理：接触状态改为“压制与脱离”——每次接触后战术层按转速比、位置重新选择，执行层用球头的牵引预算沿切向 / 外侧离开，碗面重力把它拉回再碰；
  这与被禁止的 stallBreak 的区别是：没有“检测到僵持 → 施加脱困”的规则触发，没有借来的咬合度，力在预算之内且每一次都是普通的战术选择。
  针尖对针尖（同一测试的第二部分）牵引预算极低，C 也可能仍超过 1.6 s——这是预期风险，若出现，按数据把“中心平台”（E-CF 已显示针尖镜像最长低速段 79 → 9 s）重新提交决定，而不是加脚本。

## 8. 三条路线对比

| | A 刚体 + 辅助执行器 | B 只改 AI | **C 分层混合** |
|---|---|---|---|
| 能否解决“线性下降 / 越慢越直 / 失衡过短” | 理论上能，但 M4-B 三轮都没找到可行参数区 | 不能（问题在运动公式） | 能（直接改这三条公式，且有物理来源与上限） |
| 战术（切入、追击、逼墙、连击） | 需要在刚体上做控制，难 | 能 | 能（战术层独立） |
| 开发成本 | 高：480 Hz、全局重标定、平衡重来 | 低：1–2 周 | 中：执行层拆分 + 两条新律 + 战术输出改造，约 3–4 个实验轮次 |
| 性能 | 物理 ×4–7（A1 实测） | 不变 | 120 Hz，执行层每步常数次计算，预算 ≤ +20% |
| 调试难度 | 高（吸引子、数值收敛、参数耦合） | 低 | 中：执行层是纯函数可单测；每个请求有账本 |
| 长期维护 | 高（任何零件改动都牵动物理尺度） | 低，但合成公式继续累积补丁 | 中：零件差异集中在执行层参数表，规则清楚 |
| 主要风险 | 不收敛 | 体验问题不解决 | μ_trac 等游戏尺度参数需要标定；针尖僵持可能仍需要场地层决定 |
| 回滚 | 难 | 易 | 易：执行层开关整体回到现有 preStep 路径（golden 不变） |

## 9. 可以与 M4-C 并行的工作

不依赖运动模型细节、只依赖接口的工作都可以并行（v2/s3-experience，PR #13 已有挑战 10 关、收集与解锁、存档 v3、完整设置面板）：
- 挑战模式关卡流程、解锁与收藏、存档迁移、设置面板、陀螺库锁定态、结算页——**可以继续**；关卡里与胜率有关的门槛（例如“击败某构筑”）等 M4-D 之后统一复核数值。
- M6 模型与视觉、撞击三档的视听反馈（只读 `impactTiers`）、性能测量脚手架、端到端用例——可以继续。
- 竞技场几何（中心平台）不并行：它与 P2.3.1 的结论耦合，等 C 的僵持数据。
- 平衡调参（零件数值）不并行：等 C 定型后的 M4-D。
