## 0. 结论摘要

1. **现有牵引折算成执行层系数**：按静态法向力，高转速档（ω/ω₀ ≥ 0.6）的等效 μ 中位为烈刃（橡胶）0.95、森衡（平齿）1.16、紫曜（球头）0.41；
   磐盾（针尖）只有墙边 / 脱困借来的牵引（1930 步，μ ≈ 0.41）。现有牵引随转速比例线性下降，μ·N 与转速无关——按高转速档取 μ 时，中、低转速档的牵引约为现在的 1.8 倍和 4 倍，除非 ω·d_eff 上限起作用。
2. **N 的噪声很大，但均值正确**：按 120 Hz 观测，橡胶 / 平齿在接地判定为真的步里有 26–34% 的步 N_lag = 0（求解器接触时有时无 + 短跳），球头 14%、针尖 6%；
   N_lag 的均值 ≈ 1.05–1.12 m·g。一拍滞后与同步 N 在 16–19% 的步上“有 / 无”不一致。直接用 μ·N_lag 会得到均值正确、逐步脉动的牵引。
3. **d_eff**：d_geo = ρ·sin θ_rel 与实测接触点偏移在中位上一致（差 0.001–0.002）。按 d_geo，高转速档 ω·d 中位为烈刃 4.4、森衡 3.8、紫曜 1.7、磐盾 0.4 u/s，
   **低于烈刃 / 森衡现在的水平速度中位（5.5 / 6.3 u/s）**；按整圈边缘 d = ρ，ω·d 为 14–17 u/s，几乎从不起作用。d_eff 的定义直接决定 C3 能否保留现在的速度。
4. **能量形式的成本**：现有牵引做的功按功率形式（η = 1）从自转扣，是现行固定费率的 **6.5 倍（烈刃）、7.9 倍（森衡）、3.9 倍（紫曜）**；
   力矩形式 + d_geo 为 5.9–10.7 倍，+ d_rim 为 40–48 倍；η < 1 时按 1/η 放大（η ≈ 0.3–0.5 即落在 10–30 倍）。
   一阶估计（轨迹不变）：回合时长均值 18.9 → 15.8 s（−16%），中位 13.5 → 9.5 s；含攻击 / 平衡型的对阵缩短 23–41%，防守 / 耐力互打不变。
5. **姿态**：现有自稳 PD 力矩 τ_PD 与 I_a·ω 之比 K 的中位为攻击 / 平衡 0.36–0.43 rad/s、防守 0.05、耐力 0.11；转速越低 K 越大。
   合成进动角速度（≈ 4 rad/s）是重力进动 Ω_p = m·g·l / (I_a·ω)（0.5–0.8 rad/s）的 5–8 倍。τ_PD 中位是典型倾角下重力倾倒力矩的 2.4 倍（攻击 / 平衡）。
   姿态做的功只有自转初始能量的 0.1–0.7%，按能量形式扣转速对时长几乎没有影响。
6. **Ω_ref 不能取 Ω_p**：I_a·ω·Ω_p = m·g·l 与转速无关，会让“刚度 ∝ ω”失效；数据支持 Ω_ref 取常数，量级见 §3.3。
7. **接触**：两台之间的物理接触段全部很短（P50 0.017 s，最长 0.31 s，320 回合里没有 ≥ 0.5 s 的连续接触，球头镜像也一样）。
   把间隔 ≤ 0.25 s 的接触合并成簇，最长也只有 1.8 s。真正长的是“贴近但不动”：按 P2.3.1 的僵持定义占全部回合时间的 36%，
   几乎都在含磐盾（针尖）的对阵里（磐盾镜像 93%）；球头镜像 7.6%，最长一段 13.6 s。见 §7。
8. **C2 具备预注册条件（需先确认 §9 的两项）；C3 尚不具备**——能量耦合使时长缩短、d_eff 定义与 N 的处理三件事需要先决定；C4 依赖 C2、C3。

## 1. 测量手段与验证

- **只读探针** `EXECUTOR_PROBE`（`motionExecutor.ts`）：四个阶段在原位置把已经算出的中间量交给诊断脚本，不调用 Rapier、不写状态。CI 证明（run 43128806877 与 43129443527 均通过，`executor.test`）：
  ① 探针开启的执行层与旧路径并排推进，两台刚体的全部读写调用逐位相同；② 探针报告的每个冲量与刚体实际收到的 `applyImpulse` 参数逐位相同；
  ③ 探针开启时 golden 全部 180 场逐场一致。
- **样本**：S1 签名矩阵筛选集 320 回合（16 个有序对阵 × 20 种子，与 M4 计划的筛选集相同）；S2 单台套件 36 台（4 签名 × 3 力度 × 2 种子 + 森衡刀刃 / 棘轮换 4 种轴心 × 3 种子，最长 150 s）。
  S2 只为观测登记了主体名（`contactOwner`、ContactService 主体），不影响物理。
- **窗口**：排除发射过渡（S1：意图仍为 `launch`；S2：发射后 1 s 内）与爆裂后；“典型”= 接地且过去 0.5 s 内两台没有身体级接触；“撞击后”= 身体级接触开始后 0.5 s 内。
  转速档：hi = ω/ω₀ ≥ 0.6，mid = 0.3–0.6，lo < 0.3。分布每 2 步取 1 个样本，计数与求和每步都算。
- **口径**：I_a = 游戏层 `spinInertia`；横向力矩 τ = I_t·Δω_⊥ / dt，I_t = `massProps.It`；N_lag = 执行层在本步开头读到的上一子步轴心-地面法向冲量 / dt（C3 实际能用的量），
  N_post = 本步求解后的同一量；“接地”是游戏现有的位置判定（距地面 < 0.12），不是接触判定。

- 预算 c_g·I_a·ω·Ω_ref 若取 Ω_ref = Ω_p，等于 c_g·m·g·l，**与转速无关**，“刚度 ∝ ω、低转速更易被放倒”就不成立；所以 Ω_ref 应取常数。
  以 c_g·Ω_ref = 1 rad/s 为例，现有 PD 超出预算的步占 5.7–7.5%（攻击 / 平衡）、≈ 0（防守 / 耐力）；取 3 rad/s 为 0（§6）。

### 5.3 对回合时长的影响（一阶估计，轨迹不变）

沿实测轨迹重算假想转速：ω′ ← ω′ − (该步实际掉速 − 该步账本 drive) − max(W, 0) / (I_a·ω′)，η = 1。轨迹在新规律下一定会变，这只是量级。

## 9. C2 / C3 / C4 是否具备预注册实验的条件

- **C2（姿态律）：具备，需先确认两点。** ① Ω_ref 取常数（数据说明取 Ω_p 会使预算与转速无关）；② 进动由谁决定（合成进动比重力进动快 5–8 倍，改慢会影响现在依赖进动相位的牵引方向）。
  C1 给出了 K 的分布、按转速档的变化与超出比例，可以据此为 C2 选 2–3 个 c_g·Ω_ref 臂做预注册。姿态的能量成本很小，不影响时长。
- **C3（牵引律）：尚不具备。** 三件事需要先决定，否则预注册的门槛无法写：
  ① 能量耦合：按 C3 候选规格（功率形式、η ≤ 1）从自转扣，攻击 / 平衡型的牵引成本是现在的 4–8 倍以上，回合时长一阶估计缩短 16%（均值）、含攻击 / 平衡型的对阵 23–41%；
     是接受更短的回合、降低牵引功率，还是调整自转能量尺度——这涉及比赛时长这一产品方向，需要 Huang 决定；
  ② d_eff 的定义（d_geo 会让攻击 / 平衡型变慢，ρ 不起作用）；
  ③ N 的使用方式（逐步 / 滤波）。
- **C4（战术层）：依赖 C2 与 C3**，暂不具备。C1 的接触数据说明两台之间没有长时间连续物理接触，“僵持”的度量应使用几何 / 速度定义（P2.3.1）而不是接触段。
